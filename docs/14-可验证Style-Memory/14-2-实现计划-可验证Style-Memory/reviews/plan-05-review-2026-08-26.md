## 代码审查重点核验

### 1. 详情四分区与缺失标注（AC-09）

- `style-memory-detail-view.tsx`：验证依据（参考图/代表结果并排 + 图注 exact「参考图」「代表结果」+ 来源 Iteration `focus={id}` 链接）、保留的风格（styleTokens 标签 + retainedRules 勾选样式清单）、可替换内容（逐项默认值，空默认值「必填」）、排除约束与增强方向、使用情况（lastUsedAt null →「尚未使用」+ 派生 N 次）全部来自 DTO 真实字段。
- 缺失标注：每分区/子区独立判空，`MissingNote` 原位「待补充 / 来源缺失」说明；无占位真图、无其他数据顶替（e2e TC-9.1 断言 `img` 计数 0 + 原位文案）。代表结果图 `onError` → 「暂不可用」且徽标不受影响（边界 3）。
- 高级信息：`advancedExpanded` 默认 `false`，`aria-expanded + aria-controls` 原位展开（TC-3.1/TC-9.1 断言默认不可见、展开后可见）。

### 2. 编辑表单

- `ruleSetsChanged` 为 **import**（`style-memory-edit-form.tsx:9` ← `@/lib/style-memory-rules`，plan-01 交付的唯一实现），非复制实现；与已加载原值比较，仅元数据变化 →「保持用户已验证」，规则集合实质变化 →「保存后状态将变为：待验证」（组件测试 3 分支 + 顺序不变分支锁定）。
- 提交 PUT 五字段（name/description/variables/retainedRules/negativeConstraints，无 `verificationStatus`，ADR-1）；非 2xx（含 409）显示服务端 `error` 文案并 `return` 保留表单与输入；成功 → 关闭 → 失效列表缓存 → `onSaved()` 触发 `query.refetch()` 回读刷新，**无任何乐观更新**（风险备注契约满足）。
- 名称错误时机：中性帮助文案常驻，`nameTouched || submitAttempted` 才显示错误（组件测试锁定「提交前无 alert」）。

### 3. 代表结果选择器

- **取消零请求**：POST 仅存在于 `handleConfirm`；关闭/Escape 经 ModalDialog `onClose` 直接关闭，不发请求（TC-5.5/TC-8.3 断言 `representativeResultRequests` 为 0）。挂载即 GET 与「加载更早」游标为规格内请求。
- **相关集服务端判定**：候选直接渲染 `/representative-candidates` 响应 items，前端无任何本地过滤/排序；空候选解释相关范围（派生 ∪ 来源、completed 且有结果）。
- 确认 → POST `{ generationTaskId }` → 成功关闭 → 失效列表缓存 → 回读详情（转已验证 + 新代表结果），无乐观更新。

### 4. 删除 / 复制

- `style-memory-delete-dialog.tsx`：`destructive` ModalDialog（原语层强制禁用遮罩关闭，TC-7.1 背景点击实测不关）；文案含名称与「仍会保留：来源参考图、来源 Iteration、代表结果和历史生成记录。」；确认 → DELETE → 失效 `["templates"]` 缓存 → `router.push(listHref)` 恢复原查询（列表页写入 sessionStorage 的 search/status）；失败保留弹层可重试、不重复导航。
- 焦点落点：列表页挂载 `listTitleRef.current?.focus()`（主标题 `tabIndex={-1}`，plan-03 确认导航约定；TC-8.4 断言 activeElement 落 `style-memory-page` 内）。
- 复制：`copy.id` 取自服务端 201 响应体（非前端拼造）→ 跳 `/workspace/templates/{copyId}?notice=rename` → 「已创建复制品，从『待验证』开始；建议重新命名…」提示（TC-5.3 断言 `(copy)`/待验证/无代表结果图/重命名提示）；失败保留页面上下文展示错误（header 内 role="alert"）。

### 5. iterations focus 支持

- `iterations/page.tsx`：`focus` 参数 → `pendingFocusId` → 列表非 loading 后 `setSelected(target.id)` 联动既有选中态（详情面板打开）+ `scrollIntoView` 高亮 → 一次性消费（`setPendingFocusId(null)` + `router.replace` 清除参数）；目标不在当前列表窗口时静默忽略（与验收标准口径一致，TC-3.2 覆盖命中分支）。实现模式与 templates 页既有 focus 模式对齐（计划指定）。

### 6. 清单外改动最小性

- `templates/page.tsx`：仅两处 plan-05 注释标记的改动——①挂载聚焦主标题（TC-8.4）；②URL 持久化 effect 内同步写 `STYLE_MEMORY_LIST_QUERY_STORAGE_KEY`（TC-7.3，sessionStorage 不可写时降级无查询返回）。其余为 plan-04 既有内容。
- `style-memory-view-model.ts`：仅新增导出常量 + 注释（16 行文件内 +9 行）。两处均记录于「风险与边界 > 实现备注」。注：该节「允许修改的额外文件: 无」与实现备注并列存在表述张力，但实现备注即属风险与边界章节的记录，按 skill「清单外改动需记录」口径判定成立。

| 决策 | 核验结果 |
