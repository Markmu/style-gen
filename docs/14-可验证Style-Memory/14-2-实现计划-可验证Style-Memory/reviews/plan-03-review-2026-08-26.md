**偏差 1（类型）**：计划规格 `initialFocusRef?: React.RefObject<HTMLElement>`，实现为 `React.RefObject<HTMLElement | null>`（`use-focus-trap.ts` L34、`modal-dialog.tsx` L29）。
**评估：合理**。React 19 类型下 `useRef<T>(null)` / `createRef<T>()` 产物即 `RefObject<T | null>`，消费方（含本仓 `DropdownMenu` 传入 `useRef<HTMLDivElement | null>(null)`）无法以非 null 类型实参满足原签名；这是类型系统正确性要求，非语义放宽（运行时仍以 `?.current ?? null` 兜底）。

**偏差 2（事件阶段）**：计划规格"容器 `keydown` 捕获 Tab / Shift+Tab"，实现挂**冒泡阶段**（`use-focus-trap.ts` L14-15 JSDoc 说明）。
**评估：合理且必要**。若按捕获阶段，外层弹层容器会先于内层收到事件（捕获自根向下），嵌套场景（边界场景"菜单中打开确认层"）中内层 trap 无法接管；冒泡阶段下最深的监听先执行，Escape 通过 `stopPropagation` 抢先消费（L134-138），Tab 通过 `preventDefault` + 外层 `defaultPrevented` 早退守卫（L131-133）避免二次移动焦点。规格其余语义（Tab 循环、还原、选择器）不变。

两处偏差均已在源码 JSDoc/注释中说明依据；未在计划文件中回写偏差记录，记为本报告建议项 S5。

## 维度 9：代码审查 — 无 blocker，4 项建议

### 审查重点结论（按指定关注点）

1. **use-focus-trap 焦点还原**：active 边沿（effect 依赖 `[active]`，false→true 记录、cleanup 还原）与 unmount（组件卸载时同一 cleanup 执行）双路径覆盖；`restoreTarget?.isConnected` 防止聚焦已随背景卸载的元素。正确。
2. **Tab 循环实时查询**：每次 keydown 现查容器可聚焦列表，动态增删生效；焦点在列表外（`currentIndex === -1`）时 Tab 落首元素、Shift+Tab 落末元素，边界自洽。
3. **双环境可见性口径**：见维度 7——jsdom/真实浏览器分支正确，fixed 豁免是对规格原文的正确性修正。
4. **嵌套 stopPropagation 语义**：Escape 内层 `preventDefault + stopPropagation + 回调`；Tab 依赖 `defaultPrevented` 早退防外层重复处理（因 Tab 不可 stopPropagation——否则会阻断原生后续无、但会破坏 React 合成事件到达菜单 keydown 处理器，实现取舍正确）。逐事件路径推演（Escape/Tab/Arrow/Enter/Space 于"菜单嵌套于弹层"）均无双重响应或漏响应。
5. **ModalDialog destructive/closeOnOverlayClick**：`overlayClosable = closeOnOverlayClick && !destructive` 编译期优先级，destructive 显式传 `closeOnOverlayClick` 也不生效（用例 6 覆盖该组合）。
6. **aria**：`role="dialog"` + `aria-modal="true"`；`label` 必填渲染 aria-label，`labelledBy` 提供时按 ARIA 优先级覆盖命名（用例 2 断言）；未用 `aria-hidden` 包裹背景，规格明确"不要求 inert"，Tab 循环天然隔离。
7. **命中面积**：关闭按钮 / 菜单触发器 / 菜单项均 `min-h-11 min-w-11`（11×4=44px），测试以 Tailwind 类解析断言 ≥44（jsdom 无布局的可落地等价口径，red 证据"测试口径约定"落实）。
8. **DropdownMenu APG**：`tabIndex={-1}` + 实焦点移动的 roving focus（非 aria-activedescendant，两法皆合规）；Home/End、关闭态方向键开菜单为超出计划的 APG 增益。
9. **Enter/Space 不双触发**：菜单项为 `div[role=menuitem]`（非原生 button），Enter/Space 不产生合成 click，键盘路径仅 keydown `selectItem`、指针路径仅 onClick，无双触发面。
10. **Escape/外部 pointerdown 关闭还原**：document 级 `pointerdown` + `rootRef.contains` 判外关闭；两条关闭路径均经 trap 卸载还原焦点到打开前元素（触发按钮）。
11. **danger 双通道**：错误色文字 + Trash2 图标 + 文字标签，不只依赖颜色（用例 7 断言 svg 存在）。

### 建议项（均不阻塞）

- **S1**：`dropdown-menu.tsx` L158 渲染条件 `open && items.length > 0` 与 `openMenu` 无条件 `setOpen(true)` 组合下，`items` 为空数组时点击触发器会出现 `aria-expanded="true"` 但无菜单的状态。计划消费方恒传非空 items，建议后续在 `openMenu` 或渲染条件处收口。
