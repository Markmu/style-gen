## 代码审查重点核验

### 1. prefill 纯函数（架构 §6.3 一致性 / missing 不虚构）

- `style-memory-prefill.ts::deriveStyleMemoryPrefill` 三分支与 §6.3 逐条比对一致：V2（`retainedRules ← styleInvariants[].value` hard 优先组内原序、`negativeConstraints ← negativeConstraints`、`enhancementHints ← optionalModifiers[].defaultValue` 过滤空、`styleTokens ← fingerprint.tokens`）；V1（mustKeep/styleTags/visualKeywords + 调用方负面提示 trim 非空整体一条——流程 A `negativePromptSnapshot` / 流程 B `negativePromptText` 由宿主传入）；V2 fallback / `recipe=null` / `recipeSource=missing` 一律四组全空 + missing 全标记，无任何推测补齐；各分支空数组组进 missing。
- 函数签名相对计划规格多一个可选入参 `negativePromptText`，是实现规格 §1 自身描述的 V1 约束来源所必需（"排除约束由调用方传入负面提示文本"），属规格内落地方式而非偏差。
- 输出按 POST 上限收敛（≤12×200 / ≤16×80），保证预填值可直接随体发送（单测第三用例锁定）。

### 2. 三步向导状态联动 / 提交锁 / 失败保留

- 步骤态 `1|2|3` 在组件 state，上一步/下一步往返不清空任何已编辑内容（组件测试「步骤往返不丢内容」锁定取消勾选回写联动）。
- 「保存后状态」为步骤 3 单一文本节点 `保存后状态：{expectedVerified ? "用户已验证" : "待验证"}`，勾选变化即时重渲染（TC-4.3 含取消勾选反路径断言）。
- 提交锁：`isSaving` 同时守卫 handleSubmit 早退、ModalDialog 内保存/取消/上一步/输入控件 disabled（`handleClose` 在 isSaving 中早退），慢响应 force 连点恰 1 次 POST（TC-4.8 + 组件测试）。
- 失败保留：非 201 分支只 setError，不触碰 rules/constraints/variables/name/content/step/勾选，finally 复位 isSaving 可立即重试；409 展示服务端 `data.error`（fallback 文案与服务端同文）、5xx/网络错误显示可重试文案；重试成功不重复创建（首个 409 未落库，TC-11.1 断言全程恰 2 次 POST）。打开时以来源快照整体重置（useEffect 依赖 open+sourceKey，沿用既有模式）。
- 名称校验：`nameTouched && empty` 才报错，onChange 有值即清 touched → 首屏与进行中无提前必填错误（TC-4.7 + 组件测试锁定零 POST）。

### 3. ModalDialog 原语使用

- 向导容器由 plan-03 `ModalDialog` 承载（focus-trap 来自 `useFocusTrap` 原语），**未手写 focus 管理**；向导内唯一 autoFocus 是规则行内编辑输入框，属行内编辑 UX 而非弹层焦点管理。Escape 关闭/焦点还原由原语提供（TC-8.1：Tab×10 循环不出层、Escape 还原触发按钮）。
- ModalDialog 经本次需求新增可选 `testId` prop 把 testid 挂到 focus-trap 容器本身（向导弹层的 Tab 循环/焦点断言边界），为纯增量 prop、缺省行为不变，属合理原语扩展。

### 4. 流程 B 固定待验证预期

- `flow="workspace-draft"`：firstStep=2、不渲染 step-1 与勾选框、首屏 `save-wizard-no-representative-note` 说明区（含「当前没有代表结果」「待验证」）、步骤指示按 2 步制显示；`expectedVerified = isIterationFlow && …` 保证底部状态恒为「待验证」，不存在误判已验证路径。
- 宿主 `workspace/page.tsx` 传工作区 V2 配方与 `negativePromptText`，content 变量按既有口径并入预填（template-save-dialog 内 mergeTemplateVariables），onSave 仅关弹层（导航由向导统一负责，无双跳转）。
