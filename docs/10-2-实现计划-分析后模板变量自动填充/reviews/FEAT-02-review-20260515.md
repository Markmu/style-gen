## Blocker

1. `src/app/workspace/page.tsx:190` 和 `src/hooks/use-workspace-state.ts:312`：ready/partial 响应只检查 `analysisTemplateContent` 和状态，没有要求 `analysisTemplateVariables.length > 0`。如果 API 或旧任务返回 `analysisTemplateStatus: "ready"`、非空模板正文、但变量数组为空，`UnifiedPromptEditor` 会因 `src/components/workspace/unified-prompt-editor.tsx:61` 进入模板模式，变量面板在 `src/components/workspace/template-variable-panel.tsx:32` 展示“当前模板没有变量。”，不会按 FEAT-02 风险表要求“视为 fallback，进入文本模式并显示说明”。这会让用户看到一个不可替换的“自动模板”，也会让 `currentTemplateVariables` 被当作有效自动模板上下文保存。
