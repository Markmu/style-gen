### 未入 E2E 的分支与理由

- 名称超 50 字符禁止提交（plan-05 前端边界场景第 2 行后半）— 输入框 maxLength/行内提示属组件级校验，由 plan-05 Task 3 `save-style-memory-dialog.test.tsx` 承载（E2E 已覆盖"空名禁止提交"可观察面）。
- 保存请求 5xx（对话框内错误 + 重试，详情不变）— 与 409 同走"对话框内错误呈现 + 内容保留"路径，错误分级呈现由组件测试承载；E2E 以 409 分支代表保存失败链路（plan-05 §5 E2E 验收清单仅列 409）。
- "保存成功但详情刷新失败"与"focus 目标不在当前列表页静默忽略" — 依赖实现内部时序/极端数据形态，plan-05 边界场景表未列入 E2E 验收，建议实现方以组件测试或 TC-5.8 相邻补测承载。

### 实现方需提供的源码选择器契约（red → green 对齐用）

- 来源缺失说明: `[data-testid="iteration-save-unavailable"]`（`sourceAssetId` null 的 completed 详情渲染，文案含 missing/unavailable/cannot 语义——架构 §6.4 防御性口径），不渲染保存入口
