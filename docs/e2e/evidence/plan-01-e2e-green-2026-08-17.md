## 通过摘要（对应 plan-01 §5 后端验收断言点）

- AC-01 `status=all` 返回全部状态、pending 归并 processing、按序返回（仓库 + 路由透传用例）
- AC-01 无 `status` 参数默认 completed 且条目含既有 `id`/`resultFileUrl`/`createdAt`（超集断言）
- AC-02 `q` 生成 prompt_snapshot 与来源模板名双 ILIKE 条件（绑定参数级断言 `%q%` × 2），可与 status 组合
- AC-03 快照优先 / 存量回退（`fallback`）/ 皆无（`missing`）三来源；`sourceAssetId`/`sourceImageUrl` 缺失为 null
- `[id]` 响应超集：`resultAssetId`、`analysisTemplateVariables` 保留（use-history-restore 消费兼容断言）
- AC-06 `sourceGenerationTaskId` 归属/completed/结果资产校验，非法 400；`sourceTemplateId` 非法 400
- 401 `{ error, code: "UNAUTHORIZED", retryable: false }` 保持；404 跨用户/不存在保持；500 结构保持
- 游标 keyset 条件 + 非法游标空结果；q >100 字符 400；pageSize clamp [1,50]（LIMIT size+1 探测）
- `iteration_list_queried` / `iteration_detail_queried` 结构化日志（路由用例断言）

## 性能验收（架构 §8.1）

- 方法: 本地计时脚本（`pg` 直连本地 Docker PostgreSQL），独立 perf 用户 seed 250 条 generation_tasks（四状态混合、半数带 jsonb 快照、50 条带来源模板关联），各 50 次取 P95，计时后清理 seed 数据（库已恢复原状 4 行）。
- `GET /api/generation?status=all` 等价 SQL（含双 LEFT JOIN + ORDER BY created_at DESC, id DESC + LIMIT 21）: P50 0.45ms / **P95 0.90ms**（目标 < 500ms）
- 叠加 q ILIKE 双字段: P95 0.74ms
- `GET /api/generation/[id]` 等价 SQL（5 路 LEFT JOIN + DISTINCT ON 最新已保存模板子查询）: P50 0.46ms / **P95 0.60ms**（目标 < 300ms）
