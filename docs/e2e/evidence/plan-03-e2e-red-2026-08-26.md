## 测试口径约定（约束实现方）

- **命中面积 ≥44×44px**：jsdom 无布局（`getBoundingClientRect()` 恒 0、`offsetParent` 恒为 null，plan-03「风险与边界」已声明）。断言以渲染类中的 Tailwind 尺寸/最小尺寸类（min-w / w、min-h / h；数值刻度 1 = 4px，另支持 `[Npx]` / `[Nrem]` 任意值）解析出的宽高 ≥44px 为可落地口径，等价于真实浏览器中 `getBoundingClientRect()` ≥44px。
- **遮罩点击口径**：以 `role="dialog"` 容器的父层（固定遮罩/居中层）为遮罩，直接 `fireEvent.click` 派发（jsdom 无命中测试）；弹层本体点击不冒泡关闭由容器 `stopPropagation` 保证。
- **关闭按钮名称口径**：图标关闭按钮需具备非空可理解名称，接受 `/^(close|关闭)/i` 起始的可访问名称。
- **initialFocusRef 不可见口径**：jsdom `offsetParent` 恒 null 不可作可见性判据，测试以 `display:none` 为"不可见"样本；实现方的可见性过滤需兼容该判定（如 `getComputedStyle().display`），并保留 plan 规定的 `offsetParent` 过滤语义。

## 判定

- 失败原因是 plan-03 目标组件（`src/components/ui/modal-dialog.tsx`、`src/components/ui/dropdown-menu.tsx`）尚未实现、导入不可解析，不是测试语法或环境错误：两文件已通过 vite:oxc 解析（错误发生在其后的 import-analysis 阶段），`pnpm exec eslint` 对两测试文件 0 error 0 warning；`@vitest-environment jsdom`、`userEvent.setup()`、jest-dom 匹配器均沿用 `src/components/ui/__tests__/expandable-panel.test.tsx` 与 `history-detail-dialog.test.tsx` 的既有基建。
- 用例内容逐条对应 plan-03「实现规格」与「组件验收」清单（Tab 循环/背景隔离、Escape 与关闭按钮 + 焦点还原、destructive 遮罩双分支、aria-label 必填、命中面积、initialFocusRef 及不可见回退、菜单键盘导航/还原/触发、danger 非颜色标识），实现落地后同一命令转 green。
- 结论: **预期失败，测试有效。**
