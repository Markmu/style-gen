## 失败摘要

17 个用例全部失败于同一根因：`/workspace/templates/[id]` 路由不存在（`src/app/workspace/templates/[id]/` 目录未创建），Next.js 渲染 404 页（error-context 页面快照为 `heading "404" / "This page could not be found."`）。

首个失败断言均为：

```text
expect(getByTestId('style-memory-detail-page')).toBeVisible({ timeout: 15000 })
Error: element(s) not found
```

失败属功能缺失（plan-05 详情页未实现），非环境错误、非测试自身错误：dev server 正常启动（workspace project，端口 3001）、mock 拦截链路未被触达（页面 404 不发详情请求）、无选择器歧义报错。

## 结论

**预期失败，测试有效。** 17/17 用例因详情页未实现而失败，red 基线成立，可进入 implementer 阶段（plan-05 Task 2–8）。green 门：同一 spec 全绿 + `pnpm verify:fast`。

- 404 详情态文案含「不存在或已被删除」；503 错误态复用 `StatePresenter`（`section[data-status="failedRecoverable"]` + 重试按钮），错误态内保留「返回列表」入口
- 删除后导航回列表需把初始焦点置于列表页首要内容（`style-memory-page` 容器内，如主标题 `tabIndex={-1}`，plan-03 确认导航约定）

### 文案口径（断言依赖，PRD/架构 §7.6 术语）

- 状态徽标：`用户已验证` / `待验证`（文字，非仅颜色）
- 图注：`参考图`、`代表结果`（exact 文本）
- 待验证引导：`从相关的已完成 Iteration 选择代表结果` + 按钮 `选择代表结果`；已验证替换入口按钮名含 `替换代表结果|更换代表结果|选择代表结果`
- 编辑回退提示：规则集合实质变化 → `保存后…待验证`；仅元数据变化 → `保持…已验证`
- 使用情况：`最近使用`+时间（含年份）+ `派生 N 次`；无使用 → `尚未使用`
- 删除确认：标题含 `删除…Style Memory`，正文含 Memory 名称与 `仍会保留：来源参考图、来源 Iteration、代表结果和历史生成记录。`；按钮 `取消` / `删除`（exact）
- 复制品：名称 `{name} (copy)`，页面提示含 `重新命名|重命名`
- 空默认值变量标注 `必填`；高级信息展开控件名含 `完整提示|高级信息`；候选分页按钮 `加载更早`

### 交互契约（plan-03 原语）

- 弹层全部走 `ModalDialog`（dialog role、Tab 循环、Escape 还原；删除层 `destructive` 背景不关闭）
- 更多菜单走 `DropdownMenu`（触发按钮名「更多」，项序 编辑→复制→删除；Escape 还原触发按钮）
- 编辑表单：名称输入与 label 关联（含「名称」）；规则输入控件与 label 关联（含「核心保留规则」或「保留规则」字样，逐条 input 或整组 textarea 均可兼容）；保存按钮名 `^保存`、取消 exact `取消`；注意 Playwright 1.58 Locator 无 `getByValue/getByDisplayValue`，按值定位不可用
- 候选选择器：条目 `radio` role 且可理解名称含 promptSummary；确认按钮名含 `确认`
- 状态展示以响应 DTO 为准（ADR-1）：PUT/POST 后回读 GET 详情刷新；替换代表结果禁止乐观更新（plan-05 风险备注）
