## 失败摘要

12 个用例全部失败于同一根因：**三步向导与草稿向导未实现——现有保存入口仍打开旧单步对话框**。

- 流程 A 的 11 个用例：入口选择器正常打开旧对话框（error-context 快照均为 `dialog "Save as Style Memory"`，含 Name/Prompt content/Variables 预填，无任何步骤容器、无「设为代表结果」勾选、无「保存后状态」），首个失败断言为：
  - TC-4.1：`getByTestId('save-wizard-step-1')` 不可见（快照中 `save-wizard-step-1` 出现 0 次）
  - TC-4.2～TC-11.2：`getByRole('button', { name: /下一步/ })` 不存在（旧对话框无步骤导航）
  - TC-8.1：向导打开后焦点仍在触发按钮（`button "Save as Style Memory" [active]`），`expectFocusWithin(dialog)` 失败（旧对话框无焦点陷阱/还原）
- 流程 B 的 TC-4.9：工作区入口正常打开旧 `dialog "Save as Template"`（无 `save-style-memory-dialog` testid、无「当前没有代表结果」说明区），`getByTestId('save-style-memory-dialog')` not found。

失败属功能缺失（plan-06 未实现），非环境错误、非测试自身错误：dev server 正常（workspace project，端口 3001）、迭代列表/详情 mock 正常渲染（快照含 mock 时间戳）、工作区上传分析链路正常到达 analysis_ready、409/5xx/慢响应等 POST mock 未被提前触达。
