### 未入 E2E 的分支与理由

- 守卫三豁免之"内容一致"（提示/排除项/两参数逐字段相等）— 前置需要把工作台参数构造为与目标完全一致，而参数不在持久化通道内（`WorkspacePersistedState` 无 params 字段），E2E 无法稳定构造；由 plan-04 Task 2 `restore-guard.test.ts` 四类分支单测承载。
- "确认对话框期间用户切换详情 → 关闭对话框不应用载荷"边界 — 依赖内部时序触发，建议由 `replace-confirm-dialog.test.tsx` 组件测试承载（plan-04 Task 5）。
- `?templateId=` 直接从 Style Memory 进入工作台生成携带 `sourceTemplateId`（plan-04 §5 AC-02 前半句）— 属工作台 `currentTemplateId` 记录链路而非恢复链路；实现方在 implement 阶段可扩展本 spec 或在 TC-4.7 基础上补充（本 red 以恢复携带链路先行覆盖 AC-02 数据来源）。

### 实现方需提供的源码选择器契约（red → green 对齐用）

- 详情动作（`iteration-detail-panel.tsx` primaryActions 插槽，plan-03 已交付空占位容器 `iteration-detail-actions`）:
  - completed: 动作区内按钮 "Continue this direction"（匹配 `/continue (this |the )?direction/i`）
  - failed: 动作区内按钮 "Fix and continue"（匹配 `/fix (and|&) continue|correct (and|&) continue/i`，同一恢复链路）
  - processing 不渲染动作区（plan-03 既有行为，不回归）
- 替换确认对话框: `[data-testid="replace-confirm-dialog"]`（role=dialog），内含当前方向与目标方向的提示摘要（测试使用 ≤46 字符短提示，摘要需完整可见两侧文本）、取消按钮（`/cancel|stay|keep current/i`）与确认按钮（`/continue|switch|replace/i`）
- 工作台上一轮结果展示位: `[data-testid="previous-result-preview"]`（恢复携带 resultFileUrl 的迭代时渲染，内含 `img[src=resultFileUrl]`；failed 恢复无结果时不渲染该结果图）
- 工作台快照消费复用既有可观察位: prompt-card 提示文本、`getByLabel('Variable negative_prompt')`（排除项）、Render Dock `getByLabel('Aspect Ratio')`/`getByLabel('Quality')`（参数）、Reference Canvas `img[name="Reference"]`（来源上下文）、`getByLabel('Full Generation Prompt')`（恢复后编辑）
- 列表/详情侧沿用 plan-02/03 既有契约: `iteration-list-item[data-status]`、`iteration-detail-panel[data-status][data-iteration-id]`、`iteration-detail-actions`
- 守卫前置通道: 既有 `style-gen-workspace-state`（version 4）sessionStorage 键（`src/hooks/use-workspace-state.ts`）；恢复写入需在导航前同步 flush（架构 §6.3）
