## 关键失败输出摘要

- 仓库层（目标函数不存在）:
  - `TypeError: findStyleMemoryDetail is not a function`（详情组装、读时防御降级、usage 空值、404 null 共 4 例）
  - `TypeError: setRepresentativeResult is not a function`（原子写 representative + user_verified）
  - `TypeError: listRepresentativeCandidates is not a function`（相关集映射、谓词、游标分页共 3 例）
- 纯函数模块缺失:
  - `Error: Cannot find package '@/lib/style-memory-rules' imported from src/lib/__tests__/style-memory-rules.test.ts`——`src/lib/style-memory-rules.ts`（Task 5）尚未创建，套件 17 用例全部无法加载
- createTemplate（新列与状态派生未实现）:
  - `expected { id: 'TPL_001', …(8) } to deeply equal { id: 'TPL_001', …(16) }`——行映射缺 description / 规则四元组 / verificationStatus / representativeGenerationTaskId / sourceGenerationTaskId
  - `expected "vi.fn()" to be called with arguments: [ ObjectContaining{ "verificationStatus": … } ]`——values 未写入派生状态与新列（带 representative → user_verified、不带 → pending_verification、缺省空数组共 3 例）
- findAllByUserId（列表联查未实现，仍为旧名称单字段 ILIKE 查询）:
  - `expected { id: 'TPL_001', …(5) } to deeply equal { id: 'TPL_001', …(8) }`——条目缺 verificationStatus / retainedRulesPreview / representativeImageUrl / lastUsedAt / updatedAt
  - `expected '2025-06-15T09:59:59.000Z' to be '2025-06-15T09:59:59.000Z::TPL_002'`——nextCursor 仍为单键 createdAt，未编码 (sortTs, id) 双键
  - `expected false to be true`——传入 "ISO::ID" 游标未解码出双键 keyset 条件
  - `expected [ 'USER_001' ] to include 'user_verified'`——verificationStatus 筛选未参与 WHERE
  - `expected 1 to be 7`——搜索谓词仅 1 路 name ILIKE，未覆盖 description / array_to_string×4 / 变量聚合子查询（架构 §6.1 七路）
  - `expected "vi.fn()" to be called with arguments: [ PgTable{…} ]`——from 未以 generation_tasks 构建 LATERAL 聚合子查询，且 `.as()` 未被调用、LEFT JOIN 数不足（代表结果链缺失）
  - `expected 1 to be 2`——orderBy 仍为单键 createdAt，缺 COALESCE(last_used, updated_at) DESC + id DESC 双键
- updateTemplate（规则回退判定未实现）:
  - `expected undefined to deeply equal [ 'rule a', 'rule c' ]`——set 未写入 retainedRules / negativeConstraints / description；实质变更用例中 `verificationStatus` 派生缺失（回退未实现）；改序 / trim 用例因新列未写而失败
- duplicateTemplate（复制边界未实现）:
  - values 未包含 description / 规则四元组 / sourceGenerationTaskId / `verificationStatus: 'pending_verification'` / `representativeGenerationTaskId: null`

## 判定

- 失败原因是 plan-01 目标功能（schema 新列、StyleMemoryRecord/DTO 映射、状态派生与回退、复制边界、列表联查、详情组装与防御降级、代表结果函数、style-memory-rules 纯函数）尚未实现，不是测试代码、mock 或环境错误：测试文件自身 ESLint 0 error 0 warning；13 个通过用例全部为既有行为（关联引用图写入、variables 合并、findByName/findById/delete/既有 update 路径）与守卫用例（content 不触发回退、规则未提供不回退、(copy N) 去重算法），符合"实现后必须保持"的约束。
- 附注：测试文件引用了尚不存在的导出（`findStyleMemoryDetail` 等）与参数键（`verificationStatus` / `retainedRules` 等），`pnpm type-check` 在实现落地前对此测试文件报错属 TDD red 预期，green 阶段随 types/ repository 实现消除。
- 结论: **预期失败，测试有效。**
