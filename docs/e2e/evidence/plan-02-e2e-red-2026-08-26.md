## 判定

- 失败原因全部是 plan-02 目标功能（POST 扩展体校验与透传、GET status 白名单、详情 DTO、PUT 五字段与回退/409 统一、两个新子资源端点、templateWrite 限流配置与共享接入）尚未实现，不是测试语法或 mock 环境错误：5 个测试文件 ESLint 0 error（仅 1 条 rate-limit.test.ts 既有未使用 import warning，非本次引入）。
- 通过的 32 例为既有行为回归（既有 14 + [id] 404/401/DELETE×4 + rate-limit 既有 11）与 3 个守卫例（POST 409 code 保持、status=all/缺省不带筛选、新列表 DTO 透传、PUT 透传断言），均为"实现后必须保持"的约束。
- 附注: 新测试引用了尚不存在的路由模块与 `RATE_LIMIT_CONFIGS.templateWrite`，实现落地前 `pnpm type-check` 对这些测试文件报错属 TDD red 预期，green 阶段随路由实现消除（同 plan-01 先例）。
- 结论: **预期失败，测试有效。**
