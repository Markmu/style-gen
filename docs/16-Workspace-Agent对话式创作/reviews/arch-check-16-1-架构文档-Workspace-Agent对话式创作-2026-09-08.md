## 五、闭环检查与修订记录

本次起草并检查时已修正：

1. 模型分类后继续同步生图可能超过 150 秒：宿主预算改为 240 秒，turn 租约只覆盖解释阶段，生成开始前完成 turn 并关联任务。
2. Memory 未知保存缺乏可读回执入口：事件查询补 requestKey 模式，Memory 写与事件同事务。
3. 生成/结果事件与原 turn 请求键冲突：系统事件使用确定命名空间键。
4. 模型旧提案可能成为隐藏生成阻塞：新提案替代旧 pending 时标 stale，历史保留。
5. 固定约束只有存储无编译去向：明确合并到用户约束片段并保持来源身份，手写全文不重复叠加派生文本。
6. SDK 隐式重试可能绕过“只发送一次”：明确创建型调用单次发送，重试仅限查询。
7. 新任务 unknown 无详情字段：扩展原 GET generation/{id} 字段，公开状态保持兼容。

最终未发现未收敛的实现契约阻塞。未知外部提交的人工恢复与成本估算不确定性保持原样披露，没有因检查通过而声称已解决供应商侧全部失败情形。
