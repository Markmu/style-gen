## 三、问题汇总

最终版本未发现缺失或部分完成项。起草时已收口的源材料冲突：

- 固定 Send；图片附件发送不再另设会与最后修订冲突的切换按钮。
- 普通生成、快速复刻及失败后的图像执行都位于下方操作栏；消息中只解释和定位。
- 自然语言明确生成授权与按钮位置分开定义，不将仅修改的请求视为执行授权。
- 原型只展示近期消息、固定图片及模拟任务；正式需求要求真实对话、较早消息可读和恢复不重复执行。
- 原设计规范三栏及旧移动端约束与本期冲突已显式声明替换，后续设计规范同步仍需承接。
