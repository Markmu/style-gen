## 关键断言复核

- 已尝试 PATCH 的键与正文保持不可变；在途新编辑形成下一请求，行动前保存排空；整个保存循环绑定发起时的 epoch。
- 初始化期间附件等待同一恢复 Promise，来源读取失败不隐式创建空方向；首页 File 在初始化完成前保留，StrictMode 不吞文件。
- 成功换方向清消息及分页游标；旧账号/方向晚到响应不写入新上下文。取消或失败不清原输入。
- v5 导入首次 PATCH 503 后 migrated=false；重挂载只创建一次方向并重用完全相同 PATCH，成功后才 migrated=true，原文本始终保留。
- 变量保存与刷新后的继续编辑使用结构化 patch；本机 modifier 兼容状态只在相同服务器 revision 恢复。
- 分析原键先于动态配置复用；新上传路径绑定真实用户和 asset；未知推理保留 processing；确认结构化失败才允许复用 raw 的阶段重试。实际 SDK 网络/429/500 测试验证单次 POST。
- 旧生成断言改为 envelope 加服务器快照校验，原 prompt/negative/model/ratio/quality 校验保留；Memory 已保存状态绑定真实保存请求，未按读取次数伪造状态。
