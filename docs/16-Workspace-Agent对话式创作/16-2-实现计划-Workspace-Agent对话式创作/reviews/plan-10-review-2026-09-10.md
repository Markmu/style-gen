## 关键断言复核

- 草稿保存携带方向 requestKey，目标为新建 Memory 且不带代表结果；保存后留在当前方向，committed 先记 ID 再刷新回读，回读失败只重试读取。
- 响应未知先只读查同键回执：命中以回执 ID 完成不重发；未命中明确"未完成、未同步"，表单与原键保留，重试同键不重复创建。
- 同键同hash返回原记录（200 reused）、异hash 409、回执存在但目标已删 404 不重建；模板行与 kind='memory' 回执事件同事务。
- 重载后未确认保存不自动重放（POST 计数不变）；表单快照与待提交键 IndexedDB 持久；本机状态不称"已同步"。
- 缺 analysis 的 Memory 可编辑保存，但从其创建方向 readiness.canGenerate=false，不伪造 completed 分析；代表结果仅经用户确认写点变 user_verified，preferred 不派生验证。
