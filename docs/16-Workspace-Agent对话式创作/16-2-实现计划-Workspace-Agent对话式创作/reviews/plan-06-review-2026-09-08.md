## 关键独立核查

- 方向锁内完成原键复用、所有权、预算和 processing event，图片读取及推理在事务外；45 秒取消覆盖媒体准备，60 秒租约过期后晚到输出无效。
- 实际 Replicate/Gemini SDK 使用独立解释契约；网络、429、500 只执行一次收费 POST；没有第二轮修复或预置生产回复。
- 严格输出及 before/ID 校验失败不留下 pending changes。只有当前版本成功提案才能使旧 pending stale；旧 base 提案不能关闭新提案。
- 当前草稿与显式引用优先，历史按完整轮次裁窗，包含 responseKind、choices、references 和提案状态。更早显式事件真实回读；歧义 evidence ID 拒绝错误归因。
- 图片先验证 owned asset/成功结果，再同源、有界、无重定向读取，真实解码后缩到 384px，最多两张；原始引用 ID 不被衍生 URL 取代。
- render_request 需服务端原文明确意图、当前摘要凭据、revision、预算及无其他活动冲突；同事务完成自己的 turn 并链接生成任务，解释租约不会误杀图像生成。
- 本机先保存不可变 turn intent，再发送；未知响应查原键，失败重试新键关联 retryOf；旧方向 finally 不释放新方向 flight，poll 回读原 event 后清理本机待确认意图且保留新输入。
