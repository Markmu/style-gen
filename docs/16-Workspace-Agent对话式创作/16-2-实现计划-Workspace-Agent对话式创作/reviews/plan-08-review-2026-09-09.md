- 下栏包含真实catalog、五种画幅、Standard和明确HD限制；负向提示保留快照但不声称当前绑定独立应用。消息与失败rail只定位下栏。
- 摘要由完整IntersectionObserver可见实例确认，GET、隐藏和裁剪不算展示；方向、版本、token及本机改动校验阻止旧摘要提交。普通和quick首次POST前均在持久化await之后重检输入；显式原请求确认保持同键同体。
- generation flight使用Symbol和epoch，旧方向finally不能解锁新方向；发送、命令和生成各自隔离。未知结果先GET原键，已存在任务不重新创建。
- quick先记录不可消费pending授权，再在分析prepare事务绑定实际owned asset/task/requestKey。前端仅接受本页POST回执，不从GET恢复自动消费身份；服务端校验activation、epoch、来源、settings及模型绑定，任务创建和consume同事务。
- 修改、退出、刷新、401、切换方向、失败与晚回执使未使用授权失效，已提交任务继续属于原方向。授权前预选16:9时，3:4参考的quick仍按披露使用3:4/reference；普通分析保持16:9/user。
- 已接受附件只在仍为原附件时移除，新输入保留。正常分析不虚构对目标文字的解释，明确提示继续Send；完整首次图文旅程仍由11整合验收。
- Retry original复制已确认失败任务的完整快照与存储模型绑定；Generate current保存并展示当前稿。不可用原绑定、旧HD不静默替换。服务端原键回执检查优先于新版本与过期token重验。
