# 15-0 需求设计：Workspace 证据引导生成闭环

## 0. 文档说明

**产品核心目标**：把参考图转化为可信、可编辑的视觉风格配方，并通过“参考图 → 证据 → 生成”帮助用户在改变内容时保留可迁移风格。

**本需求定位**：在 Iteration Memory 已能完整回溯生成尝试、Style Memory 已能保存用户确认的风格规则与代表结果之后，改造 Workspace 从参考图进入到结果修正的主流程，让用户可以选择创作节奏、理解生成意图、就地比较结果，并依据风格证据完成下一轮局部调整。

## 1. 需求分析与确认

### 1.1 项目背景

当前产品已经形成“上传参考图 → 自动分析 → 查看风格证据 → 编辑生成提示与变量 → 生成结果 → 回溯 Iteration → 沉淀 Style Memory”的完整链路，并能持续保留来源身份、生成上下文和用户验证关系。

但 Workspace 内部仍存在五个连续创作问题：

1. 所有用户都必须先经过完整分析与编辑界面，缺少用户预先授权的“分析完成后先生成一张”快速路径。
2. 生成提示的顶层选择围绕变量、全文和结构化内容等表达方式组织，没有先回答用户要“贴近参考”还是“保留风格并改变内容”。
3. 系统已经知道参考图比例，却仍要求用户从固定默认画幅开始选择，可能无意改变原图构图。
4. 生成成功后，单张结果出现在阻断式弹层中，用户无法同时查看参考、证据、提示和本次结果，也无法连续比较多次尝试。
5. 用户发现结果偏差时，只能凭经验重写提示或直接再次生成，现有风格证据与提示联动没有延伸到结果修正。

本期目标是：**让用户从选择创作节奏开始，在同一个 Workspace 中完成首张结果、参考对比、偏差定位、局部修正、再次生成和满意结果沉淀。**

### 1.2 核心问题定义

| 问题 | 用户损失 |
| --- | --- |
| 单一创作节奏 | 只想先看结果的用户需要理解完整工作台后才能生成，首次价值出现过晚 |
| 生成提示入口技术化 | 用户需要先理解内容如何表示，才能表达自己真正的创作目标 |
| 画幅默认值与参考图脱节 | 用户可能在不知情时改变构图比例，并承担一次低价值参数决策 |
| 结果离开编辑上下文 | 用户无法立即比较参考与结果，需要在弹层、工作台和历史之间切换 |
| 偏差无法回到对应规则 | 用户容易盲目再次生成或重写整段提示，丢失原本有效的风格控制 |

### 1.3 关键设计决策

| 决策维度 | 最终选择 | 核心理由 | 否决方案 |
| --- | --- | --- | --- |
| 本期核心 | 建设 Workspace 内“首图 → 比较 → 局部修正 → 再生成”的连续闭环 | 第 13、14 期已经补齐长期记忆，当前最大损失发生在生成结果出现后的现场创作 | 继续扩充资产类型；会重复建设记忆层而不改善当前创作效率 |
| 创作节奏 | 提供“分析后编辑”和“快速复刻”两种入口 | 用户可以按任务选择控制优先或速度优先 | 所有用户继续使用单一路径；无法缩短首图时间 |
| 快速生成授权 | 每个新方向都由用户明确选择一次，分析完成且满足生成条件后只自动生成一张 | 避免意外消耗和循环生成，同时让快速路径仍然可预期 | 默认自动生成或记住上次快速选择；可能造成用户未预期的任务 |
| 分析完整性 | 两种入口都保留相同的完整风格证据和后续编辑能力 | 快速路径只减少等待操作，不降低结果可信度 | 为快速路径输出简化分析；会制造两套不一致的产品事实 |
| 生成提示组织 | 顶层先选择“贴近复刻 / 同风格创作”，再选择“快速 / 平衡 / 详细” | 先回答创作目标与表达深度，比先选择编辑格式更符合用户心智 | 继续以变量、全文和结构化内容作为顶层入口；偏技术化 |
| 专业编辑能力 | 变量与全文编辑保留为编辑方式，结构化内容移入高级信息 | 保留专家控制，同时降低首次决策负担 | 删除专业能力；会损失现有可控性与可迁移价值 |
| 变化透明度 | 生成前持续显示“保留什么 / 改变什么”摘要 | 用户可以确认同风格创作不是随机变体 | 只提供一个同风格变体按钮；无法解释系统做了什么 |
| 画幅默认值 | 推荐最接近参考图的可用画幅，并允许用户覆盖 | 参考图比例通常是最可信的初始构图意图 | 固定使用正方形；增加操作且容易意外改构图 |
| 结果呈现 | 成功结果进入 Workspace 内的本次结果区，不再用成功弹层中断编辑 | 参考、证据、提示和结果需要同时可见，才能连续调试 | 保留单结果成功弹层；每轮都切断上下文 |
| 本次结果范围 | 保留当前方向最近五个真实结果，较早结果继续在 Iteration 中可见 | 足以支持横向比较，又不把 Workspace 变成完整历史页 | 展示全部历史；会挤占创作空间并重复 Iteration Memory |
| 偏差判断 | 由用户指出需要调整的风格维度，系统定位相关证据、保留规则和提示表达 | 先建立可信、可解释的修正路径，不冒充自动视觉判断 | 自动输出风格保持总分；首版缺少足够可信依据 |
| 满意结果语义 | “设为本次首选”只表示当前方向的选择；保存为用户已验证 Style Memory 仍需明确确认 | 不把临时偏好冒充长期验证 | 首选结果自动成为已验证 Memory；破坏第 14 期可信边界 |
| 首版生成数量 | 每次仍生成一张，通过连续结果区支持比较 | 先验证比较与局部修正是否成立，再增加批量复杂度 | 首版同时做多张批量与补失败；扩大范围并模糊核心问题 |

### 1.4 产品范围

**本期范围**

1. 在新参考图开始前提供“分析后编辑”和“快速复刻”两种创作节奏，并说明各自后续行为。
2. 快速复刻在用户明确选择后，完成参考图分析并满足生成条件时自动生成一张；分析、证据和编辑能力仍完整可见。
3. 将生成提示顶层选择重组为“贴近复刻 / 同风格创作”和“快速 / 平衡 / 详细”。
4. 保留变量编辑、全文编辑和结构化内容查看能力，并将其放入次级或高级入口。
5. 在同风格创作中展示“保留 / 改变”摘要，并允许从摘要返回对应风格规则或可替换内容。
6. 根据参考图推荐最接近的可用画幅，明确标注推荐来源，并允许用户覆盖。
7. 将生成中、成功和失败状态放入 Workspace 内的本次结果区，成功后不再弹出阻断式结果弹层。
8. 本次结果区保留当前方向最近五个真实结果，并支持选择、比较、再次生成、设为本次首选、作为新参考和打开完整 Iteration。
9. 提供参考图与所选结果并排比较，并允许用户指出需要调整的风格维度。
10. 用户指出偏差后，页面联动展示相关观察、保留规则和生成提示表达，并提供加强保留、放宽、替换和不再保留四类调整。
11. 调整后更新“保留 / 改变”摘要，但不自动再次生成；用户确认后主动提交下一次生成。
12. 从当前首选结果进入既有 Style Memory 保存或代表结果更新流程，不改变第 14 期验证规则。
13. 保持从 Style Memory 或 Iteration 进入 Workspace 时的来源身份、原生成参数和当前未完成内容保护。
14. 完善分析失败、快速路径被阻止、生成排队、生成失败、结果来源缺失和服务不可用时的上下文保留与恢复动作。
15. 保证创作节奏、生成提示、结果选择、比较和调整操作可通过键盘完成，并在状态变化后把焦点移动到可理解的位置。

**明确不做**

1. 不做一次生成 2、4 或更多张的批量生成，也不做部分失败补全。
2. 不做按人像、海报、产品图等图像类型变化的分析分组与适配视图。
3. 不做浏览器插件、网页悬浮入口、右键捕捉或外部素材库集成。
4. 不新增关键词、提示词、作品、色卡或动作等独立资产库。
5. 不做自动风格保持总分、自动合格判定或自动替用户标记偏差。
6. 不做自动循环优化、无人确认的连续生成或后台自动重试。
7. 不改造 Iteration Memory 的完整列表和详情信息架构。
8. 不改变 Style Memory 的用户验证定义、代表结果数量或保存治理流程。
9. 不新增生成模型、额度、积分、计费或商业化体系。
10. 不进行移动端 Workspace 重设计；继续维持现有专业画布边界。

## 2. 用户旅程和用户故事

### 2.1 核心用户旅程

```text
主旅程：分析后编辑并定向优化结果

1. 用户进入 Workspace，准备开始一个新方向。
2. 用户选择“分析后编辑”，再选择或上传参考图。
3. 页面完成分析，并展示参考图、风格证据、保留规则和可编辑内容。
4. 用户选择“贴近复刻”或“同风格创作”，再选择快速、平衡或详细的表达程度；需要精细控制时，可以继续使用变量、全文或高级结构化内容。
5. 若选择同风格创作，用户在“保留 / 改变”摘要中确认要保留的风格规则和要替换的主体、场景等内容。
6. 页面推荐最接近参考图的画幅；用户可以接受或主动选择其他画幅。
7. 用户点击生成。本次结果区出现生成中状态，其他分析和编辑内容保持可见。
8. 生成成功后，真实结果进入本次结果区并自动成为当前选择，页面不弹出阻断式成功弹层。
9. 用户打开比较视图，并排查看参考图和当前结果。
10. 用户选择一个需要调整的风格维度，例如构图、色彩或光线。
11. 页面定位该维度对应的观察、保留规则和生成提示表达；用户选择加强保留、放宽、替换或不再保留。
12. “保留 / 改变”摘要更新，用户确认后主动生成下一张。
13. 新结果进入本次结果区，用户在多个结果之间切换比较，并把满意结果设为本次首选。
14. 用户可以继续创作、把首选结果作为新参考，或进入既有流程将其保存为 Style Memory 的代表结果。

快速旅程：先得到一张可评估结果

1. 用户选择“快速复刻”，页面说明分析完成且可生成后会自动生成一张。
2. 用户选择参考图并确认开始。
3. 页面依次显示分析和生成状态；两者使用与深入路径相同的完整创作上下文。
4. 若分析完成后满足生成条件，系统只自动提交一次生成。
5. 结果出现后，用户仍可查看全部证据，切换创作意图与详细程度，并进入相同的比较和局部修正流程。
6. 若分析完成后仍缺少必要内容或生成服务不可用，页面停止自动提交，说明阻止原因，并让用户补充内容或稍后主动生成。

复用旅程：从 Style Memory 或 Iteration 继续

1. 用户从 Style Memory 或 Iteration 进入 Workspace。
2. 页面持续显示当前来源身份，并恢复原有风格规则、可替换内容、生成提示和原生成设置。
3. 原生成设置优先于参考图推荐，不被新默认值静默覆盖。
4. 用户修改当前方向并生成，结果进入新的本次结果区；来源关联继续可见。
5. 用户把新的满意结果设为本次首选，但只有完成既有确认流程后，Style Memory 的代表结果或验证状态才会变化。

异常旅程

1. 分析失败时，快速复刻不会继续生成；页面保留参考图并提供重试分析或更换参考图。
2. 生成排队时，本次结果区显示正在等待，并说明参考、证据、提示和设置仍被保留；用户可以继续查看但不能重复提交同一任务。任务成功后，真实结果进入本次结果区；任务失败后，页面进入保留上下文的失败状态，用户决定返回编辑或主动重试，排队旅程结束。
3. 生成失败时，失败位置说明原因和仍被保留的内容；用户可以返回编辑或主动重试，系统不自动重试。
4. 用户准备更换参考图、使用结果作为新参考，或切换到另一条 Memory / Iteration 时，如果当前方向存在未完成调整，页面先说明即将切换的内容；取消后当前状态保持不变，确认后进入目标方向，原方向及其结果仍可从 Iteration Memory 找回，切换旅程结束。
5. 当前方向的结果超过五个时，最早结果离开本次结果区但继续保留在 Iteration Memory，用户不会失去历史记录。
6. 结果图或部分来源暂不可用时，页面不显示假图，仍展示可用证据、提示和设置，并提供打开完整 Iteration 或重试加载的动作。

键盘旅程

1. 用户仅使用键盘进入本次结果区，选择一个真实结果并打开参考与结果比较。
2. 焦点进入比较内容，用户依次访问可用风格维度、相关观察与调整动作，并选择应用、取消或关闭。
3. 用户取消或关闭时，焦点回到原结果的“与参考比较”；用户应用调整时，焦点移动到更新后的“保留 / 改变”摘要，并说明本轮变化。
4. 用户继续到生成操作或返回编辑；新结果完成时状态通知不夺取当前焦点，键盘旅程结束。
```

### 2.2 用户故事

**核心用户故事**

| # | 用户故事 |
| --- | --- |
| US-01 | 作为只想先看结果的创作者，我希望在开始时选择分析后自动生成一张，以便更快判断这张参考图是否值得继续。 |
| US-02 | 作为需要控制创作方向的用户，我希望选择贴近复刻或同风格创作，以便系统按我的真实目的组织生成提示。 |
| US-03 | 作为不想理解复杂提示结构的用户，我希望选择快速、平衡或详细，以便控制表达深度而不必先学习专业格式。 |
| US-04 | 作为从参考图开始的创作者，我希望系统推荐接近原图的画幅，以便避免无意改变构图。 |
| US-05 | 作为连续调试结果的创作者，我希望在 Workspace 内保留并比较本次多个结果，以便不离开编辑上下文就判断方向。 |
| US-06 | 作为发现结果偏差的创作者，我希望指出偏离的风格维度，并直接调整对应规则，以便只修改必要部分。 |
| US-07 | 作为得到满意结果的创作者，我希望把它设为本次首选并沿用既有确认流程沉淀，以便长期复用真正认可的方向。 |

| # | 用户故事 |

| US-10 | 作为遇到分析或生成异常的用户，我希望清楚知道哪些内容仍被保留以及下一步可以做什么，以便恢复后继续而不是重新开始。 |
| US-11 | 作为键盘用户，我希望能够选择结果、打开比较、调整规则，并在应用或取消后到达明确的继续位置，以便连续完成创作。 |

## 3. UX/UE 设计

### 3.1 线框图与说明

**新方向入口**

```text
┌──────────────────────────────────────────────────────────────────────┐
│ START A NEW DIRECTION                                                │
│                                                                      │
│ 你希望怎样开始？                                                     │
│                                                                      │
│ ┌─────────────────────────┐  ┌─────────────────────────┐             │
│ │ 分析后编辑               │  │ 快速复刻                 │             │
│ │ 先检查证据和生成提示     │  │ 分析完成后自动生成 1 张  │             │
│ │ [选择]                   │  │ [选择并确认]             │             │
│ └─────────────────────────┘  └─────────────────────────┘             │

│                 [拖入参考图，或选择文件]                             │
```

### 3.2 关键状态

| 状态 | 页面表现 | 用户下一步 |
| --- | --- | --- |
| 新方向未选择节奏 | 展示两种创作节奏及其后续行为，分析后编辑为安全默认 | 选择节奏并上传参考图 |
| 快速复刻待确认 | 明确说明分析完成且可生成后会自动生成一张 | 确认开始或改为分析后编辑 |
| 正在分析 | 保留参考图，显示当前在读取参考内容；快速复刻同时说明下一步将自动生成 | 等待、取消当前方向或返回分析后编辑 |
| 分析完成且可生成 | 显示完整证据、创作意图、表达程度、保留/改变摘要和画幅推荐 | 编辑或生成；快速复刻自动提交一次 |
| 分析完成但不能生成 | 显示已有证据和明确缺失内容，不自动提交 | 补充内容、调整规则或稍后生成 |
| 正在生成 | 本次结果区显示生成中或排队状态，三栏内容继续可查看 | 等待或继续检查当前设置 |
| 首个结果完成 | 结果进入本次结果区并成为当前选择，工作台不被弹层覆盖 | 比较、设为首选、调整或再次生成 |
| 多结果可比较 | 当前方向最近五个结果横向排列，首选和当前选择分开标识 | 切换结果、比较或选择首选 |
| 比较中未选择维度 | 参考与结果并排，展示当前分析中真实存在的风格维度 | 选择需要调整的维度或关闭比较 |
| 已选择偏差维度 | 展示对应观察、保留规则和生成提示表达 | 加强、放宽、替换、不再保留或取消 |
| 调整待生成 | “保留 / 改变”摘要突出本轮调整，不自动提交 | 确认后主动生成或继续编辑 |
| 生成失败 | 失败位置说明原因和已保留内容 | 返回编辑或主动重试 |
| 结果或来源不可用 | 不显示假图，保留可用上下文 | 重试加载或打开完整 Iteration |
| 切换方向待确认 | 对比当前方向与将进入的参考、Memory 或 Iteration | 取消或确认切换 |
| 服务不可用 | 说明分析或生成暂不可用，以及仍可编辑或保存的内容 | 重试、继续编辑或稍后返回 |

### 3.3 业务规则

#### 创作节奏

1. 每个新参考方向都从“分析后编辑”开始，不自动沿用上一次的快速复刻选择。
2. 快速复刻必须在选择参考图前明确选中并确认；确认后只授权本方向自动生成一次。
3. 两种节奏产生相同完整度的内容分析、风格证据、保留规则和后续可编辑能力。
4. 快速复刻只有在分析成功且页面明确可生成时才自动提交；自动提交使用贴近复刻、平衡表达、参考图推荐画幅和当前默认生成设置，并在确认时提前说明。存在缺失内容、服务不可用或用户取消时必须停下并解释原因。
5. 快速复刻的自动提交失败后不自动重试。用户修改或恢复后必须主动重新生成。
6. 用户在分析期间改回“分析后编辑”时，本次分析继续，但分析完成后不自动生成。

#### 创作意图与生成提示

7. “贴近复刻”同时参考原图内容与风格，适合验证对参考图的理解；“同风格创作”保留已选风格规则，并以可替换内容定义新的主体和场景。
8. 快速、平衡和详细只改变生成表达的覆盖程度，不改变已经确认的主体、变量、排除项和风格规则。
9. 平衡是分析完成后的默认表达程度；从 Iteration 恢复时沿用当时的生成提示与设置，不被默认值覆盖。
10. 用户尚未手动改写完整提示时，切换创作意图或表达程度立即更新生成提示。
11. 用户已经手动改写完整提示后，再切换创作意图或表达程度时，页面必须先说明将用新选择重新组织提示；取消则保留手动文本，确认后才替换。
12. 变量编辑和全文编辑保持可达；结构化内容只用于高级查看与复制，不作为默认创作选择。
13. 同风格创作持续展示“保留 / 改变”摘要。摘要中的每项必须来自当前真实规则或可替换内容，不生成无法追溯的描述。
14. 用户点击摘要中的保留项时，定位到对应风格规则；点击改变项时，定位到对应可替换内容。

#### 画幅推荐

15. 新参考图完成读取后，页面在可用画幅中推荐最接近原图比例的一项，并标注“参考图推荐”。
16. 用户在当前方向主动选择画幅后，该选择优先于推荐，不因重新分析或修改提示而改变。
17. 从 Iteration 继续时，原生成画幅优先于参考图推荐；页面不得静默改回推荐值。
18. 无法读取参考图比例且没有可恢复设置时，才使用正方形作为回退，并不显示“参考图推荐”。

#### 本次结果

19. 生成中、排队、成功和失败状态都显示在本次结果区；成功后不弹出遮挡工作台的结果弹层。
20. 每个成功结果都必须显示真实图片，并对应一次独立 Iteration；失败或进行中状态不得使用示例图片冒充结果。
21. 新结果完成后自动成为当前选择，但不会自动成为本次首选。
22. 当前方向最多显示最近五个成功结果。第六个结果进入后，最早结果从本次结果区移除，但继续保留在 Iteration Memory。
23. 当前选择表示正在查看和比较的结果；本次首选表示用户当前最满意的一个结果。两种状态必须使用不同文案和视觉标识。
24. 用户可对当前结果执行：与参考比较、设为本次首选、沿用当前设置再次生成、作为新参考、打开完整 Iteration。
25. “沿用当前设置再次生成”仍需用户主动提交，并在提交前反映最新的“保留 / 改变”摘要。
26. “作为新参考”会开始一个新方向。若当前存在未完成调整，必须先说明切换影响；确认后原方向和全部结果仍可从 Iteration Memory 找回。

#### 比较与局部修正

27. 比较视图的第一视觉焦点是等权展示的参考图和当前结果；无法加载任一图片时明确说明缺失，不使用替代示例图。
28. “哪里需要调整”只展示当前分析中确实存在的风格维度，并提供“其他”入口；不展示虚假的自动偏差结论。
29. 用户选择一个风格维度后，页面同时展示该维度的参考观察、当前保留规则和生成提示中的相关表达；某项不存在时明确说明，而不是生成替代内容。
30. “加强保留”表示下一轮更严格遵循当前规则；“放宽”表示允许该维度有更大变化；“替换”允许用户修改目标表达；“不再保留”表示下一轮不把该规则作为风格约束。
31. 应用调整后，页面返回原 Workspace 位置，并在“保留 / 改变”摘要中标记本轮修改；系统不自动生成。
32. 用户关闭比较或取消调整时，当前选择、首选、提示和规则保持不变，焦点回到原触发结果。
33. 选择“其他”时，页面引导用户进入全文编辑，并保留参考与结果的比较上下文。

#### 来源、沉淀与恢复

34. 从 Style Memory 或 Iteration 继续时，来源身份在 Workspace 和本次结果区持续可见；新结果仍与该来源保持可理解关联。
35. 本次首选只在当前方向中表达用户偏好，不改变任何 Style Memory 的验证状态。
36. 用户从本次首选保存或更新 Style Memory 时，进入既有确认流程并预选该结果；只有用户完成代表结果与保留规则确认后，验证状态才发生变化。
37. 当前任务排队或失败时，参考、证据、提示、变量、调整和生成设置都保持可编辑或可恢复；页面必须依次说明发生了什么、保留了什么、下一步可以做什么。
38. 键盘用户打开创作节奏确认、比较或切换方向提醒时，焦点进入当前任务；关闭后回到原触发位置。结果完成后的状态通知不强制夺取正在编辑中的焦点。

## 4. 验收标准

- **AC-01：用户可以选择深入或快速的创作节奏**
  - 前置：用户进入一个尚未选择参考图的新 Workspace 方向。
  - 动作：用户分别选择“分析后编辑”和“快速复刻”完成一次参考图分析；快速复刻中确认自动生成一张。
  - 结果：分析后编辑在分析完成后停留于可编辑状态，不自动生成；快速复刻在确认时说明将采用的创作意图、表达程度、画幅推荐和生成设置，并在分析成功且满足生成条件后只自动生成一次。两种路径均展示相同完整度的参考、风格证据、保留规则和编辑能力；快速路径被阻止时说明原因且不提交生成。

- **AC-02：生成提示按创作意图和表达程度组织且不误覆盖用户编辑**
  - 前置：参考图分析完成，并已有可用生成提示、风格规则和可替换内容。
  - 动作：用户在“贴近复刻 / 同风格创作”之间切换，在快速、平衡、详细之间切换，编辑变量后再手动改写完整提示，并再次尝试切换。
  - 结果：未手动改写时，生成提示随创作意图和表达程度更新，变量、排除项和已选规则保持；同风格创作显示可追溯的“保留 / 改变”摘要；手动改写后，页面在替换文本前先请求确认，取消后原文本不变；变量、全文和高级结构化内容仍可访问。

- **AC-03：画幅推荐遵循参考与恢复优先级**
  - 前置：分别存在一张可读取比例的新参考图、一张比例不可读取的参考图，以及一条带原生成画幅的历史 Iteration。
  - 动作：用户开始新方向、主动修改推荐画幅、修改分析与提示，并从历史 Iteration 继续。
  - 结果：新方向默认选中最接近参考图的可用画幅并标注推荐来源；用户主动选择后不被后续编辑覆盖；历史 Iteration 沿用原画幅；无法读取比例且无恢复设置时回退正方形且不显示参考图推荐。

- **AC-04：生成状态与最近结果在 Workspace 内连续可见**
  - 前置：当前方向已经可以生成，并先后产生排队、成功、失败和六个成功结果。
  - 动作：用户连续生成并在结果间切换，使用比较、再次生成、作为新参考和打开完整 Iteration 等动作。
  - 结果：所有状态都在本次结果区呈现，成功后没有阻断式结果弹层；真实结果与独立 Iteration 对应；当前方向只展示最近五个成功结果，较早结果仍可从 Iteration Memory 找回；当前选择和本次首选含义清楚；作为新参考前在必要时提示方向切换且不删除原记录。

- **AC-05：用户可以从结果偏差定位并调整对应风格规则**
  - 前置：当前方向有参考图、分析证据和至少一个成功结果。
  - 动作：用户打开参考与结果比较，选择一个真实存在的风格维度，依次尝试加强保留、放宽、替换或不再保留，并测试取消和“其他”入口。
  - 结果：参考与结果并排显示；页面不输出未经用户确认的偏差结论；选中维度后展示可用的参考观察、保留规则和相关生成提示表达；应用动作会更新规则和“保留 / 改变”摘要但不自动生成；取消不改变内容；“其他”进入全文编辑并保留比较上下文。

- **AC-06：本次首选与 Style Memory 验证边界保持一致**
  - 前置：当前方向已有多个成功结果，其中一个来自 Style Memory 复用方向。
  - 动作：用户切换当前结果、设定和更换本次首选，并从首选结果发起保存或更新 Style Memory。
  - 结果：当前选择与本次首选分别显示；设置首选不会自动改变任何 Memory 的代表结果或验证状态；保存或更新时进入既有确认流程并预选该结果；完成确认后才更新代表结果或验证状态；来源 Memory 身份在整个过程中持续可见。

- **AC-07：异常和方向切换不会丢失当前创作上下文**
  - 前置：分别处于分析失败、快速生成被阻止、生成排队、生成失败、结果来源缺失、服务不可用和当前有未完成调整准备切换方向的状态。
  - 动作：用户查看状态、重试或返回编辑，并尝试更换参考图或切换至另一条 Memory / Iteration。
  - 结果：每种异常均说明发生了什么、哪些参考与编辑内容仍被保留、用户下一步可以做什么；系统不重复提交或自动重试；取消方向切换后当前内容与结果不变；确认切换后原方向仍可从 Iteration Memory 找回；键盘焦点在确认、比较与返回过程中保持连续可理解。
