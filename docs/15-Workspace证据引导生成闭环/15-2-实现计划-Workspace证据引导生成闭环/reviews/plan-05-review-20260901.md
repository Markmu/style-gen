## 6. 维度 9：代码审查

**阻塞项：无。**（无正确性错误、安全隐患、数据损坏风险或阻断下游功能的契约错误）

重点核查结论：

- `knownDirectionCompletedIdsRef` 以 null/集合区分首载（`selected ?? completed[0]`）与新完成（仅新 latest id 触发切换），selected 语义正确且不会把 feed 抖动误判为新结果；preferred 路径完全独立（仅 `handleDirectionSetPreferred` 用户操作写入，支持再次点击取消）。
- `handleComparisonApplyAdjustment` 以 try/catch 包裹 `applyInvariantAdjustment`，未知 invariantId 静默拒绝不写草稿（防御兜底），正常路径覆盖草稿、关闭面板、置摘要高亮、聚焦摘要项、polite 通知，无 submit 调用。
- 取消路径零写入：仅 `setComparisonIterationId(null)` + 焦点送回该结果的比较触发器；面板内 Escape 走同一 `onCancel`（stopPropagation 防外层干扰）。
- feed 错误路径不伪造数据：非 feed 形态响应归空、HTTP 错误抛 `DirectionFeedError`（保留 retryable 语义）、`retry:false` 由调用方显式重试；previous data 依赖 React Query 缓存不清空。
- 安全：无新增 API 端点；fetch same-origin 带 session；无 Prompt 全文/凭据日志输出。

**建议项（非阻塞）：**

- **S-1（流程卫生）**：披露①对 `prompt-card.tsx`（plan-04 交付物）的回归修复不在 plan-05「允许修改的额外文件」清单内。本次经「执行记录」完整披露并判定最小必要，可接受；建议后续跨 plan 回归修复在实施前同步扩列允许清单或由主 agent 在 README 变更记录登记，避免「先改后披露」。
