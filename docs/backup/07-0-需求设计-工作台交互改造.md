# 07-0 需求设计：工作台交互改造

## 0. 文档说明

**产品核心目标**：将 Visoryn 工作台从两段式布局升级为三段式专业工作台（左导航 + 中央工作区 + 右侧历史面板），并将模板库独立为页面，提升创作迭代效率。

**本需求定位**：04 期完成了两段式布局重构（画布+决策面板），06 期上线了 Prompt 模板系统。本期（07）聚焦工作台的交互架构升级——三段式布局、生成历史面板、Recipe 4 行编辑、模板库独立页面（含服务端支持）。

## 1. 需求分析与确认

### 1.1 项目背景

**产品当前状态**

Workspace 页面已具备完整功能闭环：上传参考图 → Gemini 视觉分析 → Visual Recipe（13 字段）→ Prompt 编辑 → fal.ai/FLUX 生成结果图。06 期新增了模板保存/加载/变量填充能力。

**存在的问题**

1. **布局跳变**：分析完成后从两列硬切到三列，无过渡动画，认知被打断
2. **右列内容过载**：空态引导、分析进度、风格配方卡片、Prompt 编辑器、输出设置、模板工具栏全部堆在右列，5+ 个功能区块竞争注意力
3. **无生成历史**：用户多次迭代生成后无法回顾之前的尝试，每次都是"一次性"的体验
4. **模板管理空间不足**：模板抽屉宽度仅 320px，无法支撑搜索、过滤和卡片浏览
5. **Recipe 信息密度过高**：风格配方卡片在摘要模式下展示 5 个字段，展开后 10+ 个字段，信息量从"不够"直接跳到"过多"

**本期目标**

用户在三段式工作台中，左侧一键切换工作台/模板库，中央区域专注于当前创作任务（上传→分析→编辑→生成），右侧随时回溯历史生成结果并恢复到工作区继续迭代。

### 1.2 核心问题定义

| 问题 | 用户损失 |
|------|---------|
| 布局跳变无过渡 | 分析完成瞬间页面结构突变，用户需要重新定位注意力 |
| 右列内容过载 | 无法快速判断"我现在该看哪里"，认知负荷高 |
| 缺少生成历史 | 多次迭代后无法回顾之前的参数组合和结果，精准迭代无从下手 |
| 模板管理空间窄 | 模板多了之后无法高效浏览、搜索、比较，降低模板复用率 |
| Recipe 展示不分层 | 5 字段摘要缺少编辑入口，完整展开又信息过载，缺少中间态 |

### 1.3 关键设计决策

| 决策维度 | 最终选择 | 核心理由 | 否决方案 |
|---------|---------|---------|---------|
| 整体布局 | 三段式：Left Sidebar + 中央工作区 + Right History Panel | 4/4 竞品均采用，已成行业标准；解决右列过载问题 | 保持两段式（补丁不治本） |
| 模板管理 | 独立页面 `/workspace/templates` | 320px 抽屉无法承载搜索+卡片网格；独立页面传达更专业的产品信号 | 保持抽屉（空间不足）；侧边面板模式（仍受宽度限制） |
| Recipe 展示 | 4 行可编辑模式（Subject/Style/Lighting/Composition） | 参照 Stitch 设计，将"阅读理解"简化为"选择修改"；保留展开完整配方 | 保持 5 字段摘要（缺编辑入口）；全字段平铺（信息过载） |
| 历史面板形式 | 纯缩略图 + 参数回溯 | 轻量级，与 Stitch 设计一致；不增加中央工作区复杂度 | 任务进度+历史合并面板（职责模糊）；参考-结果配对展示 |
| 历史面板数据来源 | 服务端持久化 + 前端异步加载 | 支持跨 session 持久化，已存储所有必要字段 | 浏览器临时缓存（关闭即丢失） |
| Left Sidebar 实现层级 | 全局布局层共享组件 | Workspace 和 Template Library 共享导航 | 页面级各自实现（重复） |

### 1.4 产品范围

#### 本期范围

1. **三段式布局**：Header + 可折叠 Left Sidebar + 中央工作区 + 可折叠 Right History Panel
2. **Left Sidebar**：品牌标题 + Generate/Library 导航 + 底部 Docs/Support 辅助链接；支持折叠为 icon-only 模式
3. **布局过渡动画**：面板出现/消失使用过渡动画，消除硬切跳变
4. **Recipe 4 行编辑模式**：Subject/Style/Lighting/Composition，每行可内联编辑，保留展开完整配方
5. **生成历史面板（含服务端支持）**：后端支持按时间倒序查询历史记录；前端缩略图列表 + 点击恢复到工作区（加载风格配方/Prompt/结果图）
6. **模板库独立页面**：搜索框 + 卡片网格 + hover "Use Template" + 标签 chips
7. **废弃组件清理**：移除旧版决策面板、生成面板、配方卡片、结果展示、对比视图、模板抽屉等已替代组件
8. **Right History Panel 可折叠/隐藏**
9. **真实上传进度**：替换当前模拟进度为真实上传进度反馈
10. **替换参考图确认流程修复**：替换参考图时不丢失新文件

#### 明确不做

- **面板宽度可拖拽调整**：本期固定宽度即可
- **模板库全文搜索 + 标签过滤 + 排序**：本期仅支持基础搜索
- **历史面板参考-结果配对展示**：本期仅展示结果缩略图
- **快捷键支持**：非核心体验
- **浏览器临时缓存恢复逻辑**：已改为服务端持久化，不再需要
- **Landing Page 改造**：03 期已完成，本次不动
- **移动端适配**：延续 04 期决策，聚焦桌面端
- **对话式交互**：Firefly 风格过重，不适合当前产品
- **节点编辑器**：ComfyUI 风格过于极客

## 2. 用户旅程和用户故事

### 2.1 核心用户旅程

**主旅程：首次生成**

```text
1. 用户从 Landing Page 点击"开始创作"，进入 Workspace
2. 看到三段式布局：左侧 Sidebar（Generate 高亮）+ 中央空态工作区 + 右侧历史面板（空态提示"还没有生成记录"）
3. 中央工作区显示上传区（虚线拖放框）+ 右侧决策面板显示创作流程引导
4. 用户拖放参考图 → 上传进度条 → 上传完成
5. 系统自动开始分析 → 中央画布显示参考图 + 分析中覆盖层
   → 决策面板显示分析进度（计时器 + 提示文案）
6. 分析完成 → 决策面板平滑过渡显示 4 行编辑卡片：
   - Subject: "城市街景，霓虹灯牌" [编辑图标]
   - Style: "赛博朋克，颗粒感胶片" [编辑图标]
   - Lighting: "人造光源，高对比度冷暖混合" [编辑图标]
   - Composition: "低角度仰拍，引导线构图" [编辑图标]
7. 用户点击 Style 行的编辑图标 → 行展开为内联编辑区 → 修改后点击确认
8. 下方 Prompt 编辑器自动填充根据 Recipe 生成的 prompt，用户可进一步调整
9. 用户选择 Aspect Ratio（1:1 / 16:9 / 9:16 pill 按钮），点击"生成"
10. 生成进度 → 完成 → 画布切换为结果图 → 右侧历史面板顶部自动新增一条缩略图
```

**迭代旅程：基于历史回溯**

```text
1. 用户查看右侧历史面板，看到之前 3 次生成的缩略图
2. 点击第 2 次生成的缩略图
3. 工作区恢复为该次生成的状态：画布显示结果图，4 行编辑卡片加载该次的 Recipe，Prompt 编辑器加载该次的 prompt
4. 用户修改 Subject 行，将"城市街景"改为"废弃工厂"
5. Prompt 自动更新，用户点击"重新生成"
6. 新结果出现在画布，历史面板顶部新增一条
```

**模板旅程：浏览与使用**

```text
1. 用户点击左侧 Sidebar 的 "Library"
2. 页面切换到模板库（URL 变为 /workspace/templates）
3. 看到搜索框 + 模板卡片网格（每张卡片：预览图 + 标题 + 标签 chips）
4. 用户搜索"赛博朋克"，卡片列表过滤
5. Hover 某张卡片 → 出现 "Use Template" 按钮 → 点击
6. 自动跳转回工作台（/workspace），Prompt 编辑器加载该模板内容
```

**异常旅程**

- **分析失败**：决策面板显示错误卡片 + 重试/更换参考图按钮，布局不跳变
- **生成失败**：决策面板显示错误信息 + "重新生成"按钮保持可用，历史面板不新增记录
- **分析排队 > 60s**：决策面板显示排队提示（amber 色），用户可继续等待或更换参考图

### 2.2 用户故事

**核心用户故事**

| # | 用户故事 |
|---|---------|
| US-01 | 作为创作者，我希望工作台有固定的导航侧栏，以便在工作台和模板库之间快速切换，而不是通过抽屉或弹窗 |
| US-02 | 作为创作者，我希望分析完成后页面布局平滑过渡而非跳变，以便我的注意力不被打断 |
| US-03 | 作为创作者，我希望风格拆解以 4 行可编辑摘要呈现，以便我能快速理解并修改关键风格维度，而非面对一大段信息 |
| US-04 | 作为创作者，我希望每次生成结果自动出现在右侧历史面板，以便我随时回顾之前的尝试 |
| US-05 | 作为创作者，我希望点击历史面板中的某次生成，工作区恢复为那次的完整状态（Recipe + Prompt + 结果图），以便我基于之前的参数继续迭代 |
| US-06 | 作为创作者，我希望模板库是一个独立页面，支持搜索和卡片浏览，以便我在模板多了之后能高效找到目标模板 |
| US-07 | 作为创作者，我希望在模板库点击 "Use Template" 后自动跳转回工作台并加载模板内容，以便从浏览到使用的流程是连贯的 |

**延伸用户故事**

| # | 用户故事 |
|---|---------|
| US-08 | 作为创作者，我希望能折叠左侧导航和右侧历史面板，以便在需要时最大化中央工作区面积 |
| US-09 | 作为创作者，我希望上传进度条反映真实的上传进度，以便我知道大文件还需要等多久 |

### 3.2 关键状态

| 状态 | 中央工作区表现 | 右侧历史面板 | 用户下一步 |
|-----|-------------|-------------|----------|
| **idle**（无参考图） | 画布显示上传区 + 决策面板显示引导 | 已有历史：缩略图列表；无历史：空态提示 | 拖放/点击上传参考图，或点击历史项恢复 |
| **uploading** | 画布显示上传进度 + 决策面板保持引导 | 不变 | 等待上传完成 |
| **analyzing** | 画布显示参考图 + 分析中覆盖层；决策面板显示进度 | 不变 | 等待分析完成 |
| **analysis_ready** | 画布显示参考图 + 风格 Tag；决策面板平滑过渡出 4 行编辑 + Prompt + 输出设置 | 不变 | 编辑 Recipe/Prompt，选择参数，点击生成 |
| **generating** | 画布显示参考图；决策面板中生成按钮变为进度态 | 面板顶部新增"生成中"进度条目 | 等待生成完成 |
| **generation_ready** | 画布切换为结果图 + 工具栏；决策面板按钮变为"重新生成" | 面板顶部新增结果缩略图 | 查看结果、对比、调整参数重新生成、或点击历史项回溯 |
| **history_restored** | 画布显示该历史项的结果图；决策面板加载该次的 Recipe/Prompt | 被点击的项高亮 | 修改参数后重新生成（作为新生成） |

### 3.3 业务规则

**布局规则**

- 三段式布局始终保持，不随状态变化增减列数。中央工作区内部的画布/决策面板比例可变，但外层三列结构固定
- Left Sidebar 在 `/workspace` 和 `/workspace/templates` 共享，通过全局布局层实现
- 左侧 Sidebar 默认展开（224px），支持折叠为 icon-only（48px）
- 右侧历史面板默认展开（224px），支持折叠/隐藏

**Recipe 4 行编辑规则**

- 4 行映射关系（风格配方维度 → 4 行摘要）：
  - **Subject**：主题 + 场景 合并展示
  - **Style**：风格标签 + 氛围 + 质感 合并展示
  - **Lighting**：光线 + 色彩 合并展示
  - **Composition**：构图 + 镜头语言 合并展示
- 每行默认显示一行摘要文本（截断到 ~60 字符）+ 编辑图标
- 点击编辑图标 → 该行就地展开为编辑区，显示该行对应的所有子字段，可逐字段修改
- 同时只能展开一行编辑（点击另一行时自动收起当前行）
- "查看完整配方"按钮展开剩余维度（画面概述、视觉关键词、保留要素、可替换要素），只读展示
- 用户编辑 Recipe 字段后，Prompt 编辑器内容不自动重新生成（避免覆盖用户手动编辑的 prompt）

**历史面板规则**

- 初始加载最近 20 条已完成的生成记录，按时间倒序排列
- 滚动到底部时自动加载更多（滚动分页）
- 每条记录显示：结果图缩略图 + 生成日期
- 当前正在进行的生成任务显示在面板顶部，带动画进度指示
- 点击历史项 → 工作区切换为"恢复"模式：画布显示该次结果图，4 行编辑加载该次 Recipe，Prompt 加载该次使用的 prompt。此时用户修改参数后点击"生成"，视为一次新的生成（不覆盖历史记录）
- 新生成完成后，历史面板顶部自动插入新条目，无需手动刷新
- 历史面板只显示当前用户的记录

**模板库规则**

- 模板库页面通过 Left Sidebar "Library" 导航进入，URL 为 `/workspace/templates`
- 卡片网格每行 3-4 张（响应式），每张卡片显示：预览图（如有）+ 模板名称 + 标签 chips
- Hover 卡片 → 图片区域覆盖半透明层 + "Use Template" 按钮
- 点击 "Use Template" → 跳转到 `/workspace`，Prompt 编辑器自动加载该模板内容
- 如果模板包含占位变量，跳转后进入变量填充流程
- 卡片右上角更多操作菜单提供：编辑、复制、删除操作
- 搜索框支持按模板名称搜索（本期基础搜索，全文搜索不做）

**按钮文案规则**（延续 04 期）

| 状态 | 主按钮文案 | Step 1 标题 | Step 2 标题 |
|-----|----------|-----------|-----------|
| analysis_ready（首次） | 生成 | 风格拆解 | 生成指令 |
| generating | 正在生成... | 风格拆解 | 生成指令 |
| generation_ready | 重新生成 | 本次生成参数 | 继续调整指令 |
| history_restored | 生成 | 历史参数 | 调整指令 |

**降级态呈现规则**（延续 04 期已有策略）

- 排队提示（分析/生成排队 > 60s）：决策面板内显示 amber 提示条
- 生成不可用：输出设置区显示错误提示 + 建议稍后重试
- 风格拆解失败：4 行编辑卡片区域显示降级提示
- 分析不可用：决策面板显示错误 + 重试/更换参考图按钮

| AC-12 | 分析或生成任务排队超过 60 秒 | 系统检测到排队超时 | 决策面板内显示醒目提示条（amber 色），用户可选择继续等待或更换参考图 / 取消操作 |
