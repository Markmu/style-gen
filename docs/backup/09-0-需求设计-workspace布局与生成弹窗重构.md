# 09-0 需求设计：Workspace 布局与生成弹窗重构

## 0. 文档说明

**产品核心目标**：让工作台成为一个稳定、充满空间感的创作编辑界面，用户能在同一屏内清楚完成参考图分析、风格理解和模板编辑，并在需要时通过弹窗查看生成结果。

**本需求定位**：在 07 期工作台交互改造和 08 期全站交互与 UI 样式改造基础上，本期聚焦工作台主区域的信息重排与空间释放，解决上传区、风格拆解、模板编辑和生成结果同时争抢空间的问题。

**相关文档**：
- 《工作台交互改造》：上一轮工作台结构与历史面板需求
- 《全站交互与 UI 样式改造》：全站视觉、状态和控件一致性需求
- 《设计系统实施手册》：Precision Glass 视觉系统约束

## 1. 需求分析与确认

### 1.1 项目背景

**产品当前状态**

工作台已具备完整创作链路：用户上传参考图，等待风格分析，查看风格拆解，编辑生成提示和模板内容，再生成同风格图片。

**存在的问题**

1. **工作区空间被过多功能同时占用**：参考图、风格拆解、模板编辑、输出设置、生成结果和历史信息容易同时出现在主界面，用户难以判断当前最重要的操作区。
2. **上传与参考图显示占比偏大**：参考图在分析完成后仍占据过多横向和纵向空间，而用户此时更需要阅读风格拆解并编辑模板。
3. **生成结果长期占用主工作台**：生成图片区域在用户尚未主动查看结果时也会挤压编辑空间，使工作台像结果展示页而不是编辑工作台。
4. **空态与分析后布局不一致**：首次进入、上传前、分析中和分析完成后的区块位置变化较大，用户在状态切换时需要重新定位上传区、风格区和编辑区。
5. **可用空间没有充分响应容器变化**：工作台主区域应占满导航栏和侧边栏之外的剩余空间，并允许内容在自身区域内上下滚动；当前体验容易出现主区留白、挤压或宽度不均衡。

**本期目标**

用户进入工作台后始终看到稳定的左右双区结构：左侧承载参考图与风格拆解，右侧承载模板编辑。参考图保持轻量占位，风格拆解获得主要阅读空间；生成结果通过对话框按需弹出，不再长期占用工作台主布局。

### 1.2 核心问题定义

| 问题 | 用户损失 |
|------|---------|
| 主界面同时承载分析、编辑和结果展示 | 用户无法快速判断当前该上传、阅读、编辑还是查看结果 |
| 参考图展示面积过大 | 分析完成后真正有价值的风格拆解空间不足 |
| 生成结果直接占用工作区 | 编辑区被挤压，连续调整提示词的效率下降 |
| 空态和分析态区块结构不同 | 状态切换造成认知跳变，用户需要重新找功能位置 |
| 主区域未稳定填满剩余空间 | 大屏下空间浪费，小屏或窄宽度下内容拥挤且滚动不自然 |

### 1.3 关键设计决策

| 决策维度 | 最终选择 | 核心理由 | 否决方案 |
|---------|---------|---------|---------|
| 工作台主结构 | 左右双区：左侧分析区，右侧编辑区 | 与核心任务顺序一致：先理解参考图，再编辑生成内容 | 继续三列并列，容易让历史和结果继续争抢主空间 |
| 左侧区域职责 | 上方小比例参考图，下方大比例风格拆解 | 分析完成后用户更需要风格信息，参考图只需提供视觉上下文 | 参考图和风格拆解平分空间，会浪费分析完成后的阅读面积 |
| 右侧区域职责 | 主体为合一编辑区，轻量生成区只放输出设置和生成入口 | 让模板编辑、完整提示词编辑和变量调整集中在一个编辑空间内，生成操作不抢占内容编辑面积 | 把模板编辑、提示词编辑和生成设置拆成多个大区，会继续造成右侧拥挤 |
| 编辑模式 | 合一编辑区支持模板模式和文本模式切换 | 用户既能编辑模板原文和变量，也能切到完整文本直接调整最终提示词 | 模板与文本分成两个固定区块，会重复占用空间并增加对照成本 |
| 生成结果呈现 | 通过对话框弹出查看 | 结果是阶段性输出，适合按需查看；关闭后用户回到编辑上下文 | 在工作台常驻展示，持续占用空间 |
| 状态布局 | 空态、上传中、分析中、分析完成保持同一左右区块结构 | 用户每个状态都能在相同位置找到上传、风格和编辑入口 | 空态另做欢迎页，状态切换会产生明显跳变 |
| 响应式空间 | 工作台占满导航栏和侧边栏之外的剩余区域，左右宽度随容器调整 | 保证常规宽屏、较窄桌面和侧边栏变化时都能维持可用比例 | 固定像素宽度，容易在不同窗口下浪费或挤压 |
| 滚动策略 | 工作台可上下滚动，左右区域内部内容可按职责滚动 | 长内容不挤压布局，用户能持续编辑和阅读 | 禁止滚动或只允许整页滚动，长风格拆解和长模板会相互影响 |

### 1.4 产品范围

**本期范围**

1. **工作台左右双区重构**：主区域整体分为左侧分析区和右侧编辑区。
2. **左侧分析区重排**：参考图上传与显示区保持小占比；风格拆解区占据左侧主要空间。
3. **右侧合一编辑区稳定化**：右侧主体区域合并模板编辑和生成提示编辑，通过模板模式与文本模式切换完成不同编辑任务；不单独设置负面提示区域。
4. **模板变量外置调整**：模板模式下，用户可以编辑模板原文，同时在模板正文之外看到变量输入框列表并直接调整变量值。
5. **轻量生成区**：生成区只保留必要输出设置、生成入口和不可用原因，占据右侧较小空间，不再与编辑区平分面积。
6. **生成结果弹窗化**：生成中的反馈和生成完成后的图片结果通过对话框呈现，不再作为主工作台常驻区块。
7. **空态与分析态一致布局**：未上传、上传中、分析中、分析完成后的默认区块位置和比例保持一致，只替换区块内容。
8. **剩余空间响应式占满**：工作台主区域占满导航栏和侧边栏之外的可用空间，并根据窗口宽度调整左右区域比例。
9. **滚动体验整理**：工作台支持上下滑动；长风格拆解、长模板编辑内容和弹窗内容都有可预期的滚动行为。
10. **状态与文案统一**：空态、上传、分析、生成、失败、结果查看等状态沿用全站的克制、明确、可行动表达。

**明确不做**

- 不改变上传、分析、提示编辑和生成的核心业务流程。
- 不新增对话式创作、节点式编辑或多图批量生成模式。
- 不重做模板库独立页面。
- 不新增生成历史的复杂筛选、对比或收藏能力。
- 不处理移动端专用布局；本期优先覆盖桌面和常规宽屏下的响应式工作台。
- 不改变产品名称、视觉方向或全站导航结构。

## 2. 用户旅程和用户故事

### 2.1 核心用户旅程

```text
主旅程：在稳定左右布局中完成一次创作

1. 用户进入工作台。
2. 工作台占满顶部导航和侧边导航之外的剩余空间，主区域呈现左右双区。
3. 左侧区域上方显示小比例上传入口，下方显示风格拆解的空态占位；右侧区域显示模板编辑的空态或可编辑入口。
4. 用户上传参考图。
5. 左侧上方区域在原位置显示参考图和上传反馈；左侧下方区域进入分析中状态；右侧编辑区保持位置稳定，并提示需等待分析完成或允许编辑已有内容。
6. 分析完成后，参考图仍保留在左侧上方的小区域，风格拆解在左侧下方展开为主要阅读内容。
7. 用户阅读风格拆解，并在右侧合一编辑区选择模板模式或文本模式。
8. 用户在模板模式下编辑模板原文，并通过模板外的变量输入框列表调整变量值；或切换到文本模式直接编辑完整生成提示。
9. 用户在右侧较小的生成区确认输出设置并点击生成入口。
10. 工作台弹出生成对话框，展示生成进度；背景工作台保持当前参考图、风格拆解和编辑内容。
11. 生成完成后，对话框展示生成图片和可执行动作。
12. 用户关闭对话框后回到原工作台位置，编辑内容、参考图和风格拆解仍保持不丢失。
13. 用户可以继续修改右侧编辑内容，再次生成并通过对话框查看新结果。

异常旅程：首次进入或无分析内容

1. 用户进入未上传状态的工作台。
2. 左右双区结构已经完整呈现，不出现另一个独立欢迎版式。
3. 左侧上方显示上传入口，左侧下方显示风格拆解空态；右侧显示模板编辑空态。
4. 用户上传后，各区块在原位置切换为上传中、分析中和分析完成内容。

异常旅程：分析失败

1. 用户上传参考图后进入分析中。
2. 分析失败时，左侧上方继续保留参考图。
3. 左侧下方风格拆解区域显示失败说明，并提供重试分析和更换参考图入口。
4. 右侧编辑区不被清空，用户仍可查看或调整已有模板内容。

异常旅程：生成失败

1. 用户点击生成后打开生成对话框。
2. 生成失败时，对话框展示失败原因，并提供重新生成和返回编辑两个行动。
3. 用户选择重新生成时，对话框继续展示生成进度。
4. 用户选择返回编辑时，对话框关闭，工作台回到生成前的编辑状态。

异常旅程：内容过长或窗口宽度变化

1. 用户在较窄桌面窗口或侧边栏展开状态下使用工作台。
2. 左右区域按可用宽度调整比例，但仍保持分析区在左、编辑区在右。
3. 风格拆解或模板内容过长时，用户可以在工作台中自然上下滑动，不需要通过布局挤压来查看内容。
4. 生成对话框内容过长时，对话框内部滚动，不遮挡关闭和主要行动入口。
```

### 2.2 用户故事

**核心用户故事**

| # | 用户故事 |
|---|---------|

### 3.2 关键状态

| 状态 | 页面表现 | 用户下一步 |
|------|---------|-----------|
| 未上传 | 左右双区完整呈现；左上为上传入口，左下为风格拆解空态，右侧为模板编辑空态 | 上传参考图或编辑已有模板内容 |
| 上传中 | 左上原位展示上传反馈；左下保持即将分析的占位；右侧保持可见 | 等待上传完成或重新选择 |
| 分析中 | 左上显示参考图；左下显示分析进度；右侧保持编辑区位置 | 等待分析完成，必要时更换参考图 |
| 分析完成 | 左上保留小参考图；左下展开风格拆解；右侧合一编辑区支持模板模式和文本模式，轻量生成区保持较小占比 | 阅读风格，编辑模板原文、变量或完整提示词后生成 |
| 生成中 | 主工作台不改变布局；生成对话框展示进度 | 等待结果或返回编辑 |
| 生成完成 | 对话框展示生成图片和下一步行动；背景工作台保持原状态 | 查看结果、关闭弹窗、重新生成或继续编辑 |
| 分析失败 | 左上保留参考图；左下展示失败说明和恢复入口；右侧不清空 | 重试分析、更换参考图或继续编辑 |
| 生成失败 | 对话框展示失败说明和恢复入口；工作台内容不丢失 | 重新生成或返回编辑 |
| 内容过长 | 工作台可上下滑动；长内容在所属区域内保持可读 | 滚动阅读或继续编辑 |
| 宽度变化 | 左右区域按可用空间调整宽度，职责和顺序不变 | 继续当前操作 |

### 3.3 业务规则

1. **双区职责规则**：左侧只负责参考图和风格拆解，右侧由合一编辑区和轻量生成区组成。
2. **参考图占比规则**：参考图上传与显示区必须保持轻量，占左侧较小空间；分析完成后不得挤占风格拆解的主要阅读区域。
3. **风格拆解优先规则**：分析完成后，左侧主要空间必须用于展示风格拆解，用户无需打开弹层或切换标签才能看到关键风格信息。
4. **编辑区稳定规则**：右侧合一编辑区在未上传、分析中、分析完成、生成中和生成完成后都保持同一位置，不因状态变化被结果图替换。
5. **生成弹窗规则**：生成图片的进度、完成结果和生成失败状态都在对话框内呈现；关闭对话框后回到原工作台上下文。
6. **空态一致规则**：未上传状态不得使用与分析完成状态完全不同的布局；空态必须预告未来内容会出现的位置。
7. **响应式宽度规则**：左右区域宽度随可用空间变化；常规宽屏下右侧编辑区必须保持足够输入宽度，左侧风格拆解不得被压缩到难以阅读。
8. **剩余空间规则**：工作台主区域必须填满顶部导航和侧边导航之外的剩余区域；不得出现主工作区无故悬空或底部大面积浪费。
9. **滚动规则**：工作台允许上下滑动；长风格拆解、长模板内容、变量列表和弹窗内容必须能被完整访问，且主要行动入口不应被内容永久挤出。
10. **上下文保留规则**：上传、分析、生成、弹窗打开关闭和失败恢复过程中，已上传参考图、已分析风格和已编辑模板内容不得意外丢失。
11. **合一编辑区规则**：模板编辑和完整生成提示不拆成两个固定大区；用户通过模板模式和文本模式在同一区域内切换。
12. **模板模式规则**：模板模式下必须允许用户编辑模板原文，同时在模板正文之外显示变量输入框列表；用户调整变量值时，不需要直接改写模板原文。
13. **文本模式规则**：文本模式下展示并允许编辑最终用于生成的完整提示词，便于用户脱离模板结构直接精修。
14. **轻量生成区规则**：生成区占据右侧较小空间，只承载必要输出设置、生成入口和不可用原因，不得与合一编辑区平分主要面积。
15. **主要行动规则**：右侧生成入口只有在必要输入满足时才可用；不可用时必须在附近说明原因。
16. **提示词规则**：生成区不单独提供负面提示；用户需要提交给生成的完整提示内容都在生成提示中阅读和编辑。
17. **状态文案规则**：所有状态文案必须说明当前正在发生什么，以及用户可以继续等待、重试、更换参考图、返回编辑或关闭弹窗中的哪一种行动。

## 4. 验收标准

- AC-01：左右双区布局
  前置：用户进入工作台。
  动作：用户等待页面加载完成。
  结果：工作台主区域分为左侧分析区和右侧编辑区；左侧包含参考图上传/显示区和风格拆解区，右侧包含合一编辑区与轻量生成区。

- AC-02：参考图小占比与风格拆解优先
  前置：用户已上传参考图且分析完成。
  动作：用户查看左侧分析区。
  结果：参考图保持在左侧较小区域，风格拆解占据左侧主要空间，并能直接展示关键风格信息。

- AC-03：合一编辑区稳定
  前置：用户处于未上传、上传中、分析中、分析完成、生成中或生成完成后的任一状态。
  动作：用户观察右侧区域并进行编辑。
  结果：右侧主体始终是合一编辑区，不被参考图、风格拆解、生成设置或生成结果替换；用户已编辑内容不因状态切换丢失。

- AC-04：生成结果弹窗呈现
  前置：用户已完成必要编辑并点击生成。
  动作：用户等待生成进度并查看生成结果。
  结果：生成进度、生成完成图片和生成失败说明都在对话框内呈现；主工作台不出现常驻生成结果区。

- AC-05：关闭弹窗后回到原上下文
  前置：生成对话框处于生成完成或失败状态。
  动作：用户关闭对话框或选择返回编辑。
  结果：用户回到打开弹窗前的工作台布局和编辑上下文；参考图、风格拆解、模板内容和提示内容保持不丢失。

- AC-06：空态与分析态布局一致
  前置：用户首次进入未上传状态，随后上传参考图并等待分析完成。
  动作：用户观察未上传、分析中和分析完成三个状态。
  结果：三个状态下左上、左下和右侧区块位置保持一致，只替换对应内容；页面不出现独立欢迎版式到工作台版式的跳变。

- AC-07：剩余空间占满与滚动
  前置：用户在带顶部导航和侧边导航的工作台中浏览。
  动作：用户调整窗口宽度，并查看长风格拆解或长模板内容。
  结果：工作台主区域占满导航之外的剩余空间；左右宽度随可用空间调整；内容过长时可上下滑动并完整访问。

- AC-08：失败恢复不清空上下文
  前置：分析或生成发生失败。
  动作：用户阅读失败状态并选择重试、返回编辑或更换参考图。
  结果：失败状态提供明确恢复行动；已保留的参考图、风格拆解或编辑内容不会被无故清空。

- AC-09：模板模式与文本模式切换
  前置：右侧合一编辑区可用。
  动作：用户在模板模式和文本模式之间切换。
  结果：模板模式展示可编辑模板原文和模板外变量输入框列表；文本模式展示可编辑的完整生成提示；模式切换不清空用户已编辑内容。

- AC-10：轻量生成区
  前置：用户已进入可生成状态。
  动作：用户观察右侧生成相关区域并准备生成。
  结果：生成区占据右侧较小空间，只展示必要输出设置、生成入口和不可用原因；生成结果仍通过对话框呈现，不占用右侧主体编辑区域。
