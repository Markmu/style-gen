# 10-0 需求设计：分析后模板变量自动填充

## 0. 文档说明

**产品核心目标**：让参考图分析完成后的首个生成模板自动带出可替换变量，并用参考图内容填好默认值，使用户无需手动拆解提示词即可快速换内容再生成。

**本需求定位**：在已有参考图风格再创作、模板变量系统和工作台布局基础上，补齐“分析完成后的首次模板可直接复用”体验；本期属于已有产品的新功能优化，重点降低从反向分析到再次生成之间的手动编辑成本。

**相关文档**：
- 《参考图风格再创作》：基础创作链路需求
- 《提示词模板化与变量系统》：模板保存、变量填值和模板管理需求

- 《设计系统实施手册》：工作台视觉与交互一致性约束

## 1. 需求分析与确认

### 1.1 项目背景

style-gen 当前核心链路是：用户上传参考图，产品分析图片风格与内容，生成可用于再创作的提示词，用户再编辑提示词并生成新图。现有模板系统已经支持用户手动保存模板、编辑变量和填写变量值。

**存在的问题**：

1. **分析后的首次提示词仍是整段文本**：用户拿到的是完整描述，不知道哪些内容适合替换、哪些内容应该保留来维持风格。
2. **变量需要用户手动拆分**：即使图片里已经明确包含主体、场景、风格、光线等信息，用户仍要自己定位文本并创建变量。
3. **默认值缺失会削弱复用信心**：如果变量一开始是空的或泛化占位，用户无法确认变量代表原图中的什么内容，也不能直接生成一张与原图语义一致的结果。
4. **快速再生成路径过长**：用户只是想把“原图里的咖啡杯”换成“香水瓶”时，需要阅读整段提示词、找位置、改文字，容易打断创作节奏。
5. **保存模板前的准备成本偏高**：用户必须先人工整理变量，才敢把分析结果保存成模板；这让模板化能力更像高级功能，而不是默认工作流。

**本期目标**：参考图分析完成后，右侧编辑区自动呈现带变量的首个模板；变量项已按参考图内容填好默认值，用户可以直接生成，也可以只改一个或几个变量后再生成。

### 1.2 核心问题定义

| 问题 | 用户损失 |
|------|----------|
| 首次生成内容是整段提示词 | 用户需要自己判断可替换点，理解成本高 |
| 主体、场景、风格等信息没有自动变量化 | 用户要重复做图片分析已经得出的拆解工作 |
| 变量默认值不是原图内容 | 用户无法确认变量含义，也不能保留原图语义直接生成 |
| 改一个创作要素需要通读全文 | 编辑效率低，且容易误删影响风格稳定的描述 |
| 模板保存依赖人工整理 | 用户不容易把一次好的分析沉淀为可复用模板 |

### 1.3 关键设计决策

| 决策维度 | 最终选择 | 核心理由 | 否决方案 |
|----------|----------|----------|----------|
| 自动变量化触发时机 | 图片分析完成后首次进入可编辑状态时自动生成 | 这是用户最需要把分析结果用于再创作的时刻，能减少从分析到生成之间的断点 | 仅在用户点击“保存为模板”时生成，发现太晚；仅在模板库中生成，脱离当前创作上下文 |
| 变量范围 | 优先识别主体内容、场景环境、视觉风格、光线色彩、材质细节、构图视角等高价值项 | 这些项最常被用户替换，也最能支撑“同风格换内容”的创作目标 | 把所有名词和形容词都变成变量，会造成变量噪音；只识别主体，无法支持场景和风格变化 |
| 默认值来源 | 使用参考图分析出的具体内容作为默认值 | 默认值代表原图事实，用户不改也能得到一条完整可用的生成提示 | 使用空值或“请输入主体”等泛化占位，会让用户必须先填写才能生成 |
| 首次展示方式 | 默认进入模板编辑视角，同时保留完整生成提示的可查看与可编辑入口 | 用户先看到可替换项，能立即理解如何改；高级用户仍可直接精修完整文本 | 只展示完整文本，变量能力不显性；只展示变量表单，用户看不到最终提示整体 |
| 生成可用性 | 所有变量默认填好，分析完成后即可直接生成 | 首次结果应该是可用起点，而不是半成品表单 | 要求用户确认每个变量后才能生成，会增加不必要步骤 |
| 保存模板行为 | 不自动保存到模板库；用户主动保存时带上当前变量和默认值 | 自动生成的首态是创作草稿，不应污染用户模板库；主动保存才代表用户认可 | 自动保存每次分析结果，模板库会快速变乱 |
| 用户控制权 | 用户可修改变量值，也可切换到完整文本直接编辑 | 兼顾快速替换和细致修改，不把用户锁死在表单里 | 只允许变量填值，会限制高级用户；只允许文本编辑，会丢失本需求价值 |
| 低置信内容处理 | 不强行生成不可靠变量；必要时退回完整提示并说明未能识别稳定变量 | 变量错误比变量少更伤害信任，首版要优先保证可理解和可控 | 硬凑固定数量变量，会出现无意义默认值 |

### 1.4 产品范围

**本期范围**：

1. **分析完成后的自动变量模板**：图片分析成功后，首次填入编辑区的内容应是带变量项的模板，而不是只有整段生成提示。
2. **默认值自动填充**：每个变量都应带有来自参考图分析结果的默认值，默认值可直接参与生成。
3. **核心变量覆盖**：在参考图信息足够明确时，至少覆盖主体内容、场景环境、视觉风格、光线色彩；可根据图片内容补充材质细节、构图视角、情绪氛围等变量。
4. **变量值快速修改**：用户可以在变量列表中直接修改默认值，修改后用于生成的完整提示同步更新。
5. **完整提示可编辑**：用户可以查看并编辑最终用于生成的完整提示；手动编辑不应意外清空变量默认值。
6. **直接生成**：用户不修改任何变量时，也可以用默认值直接生成图片。
7. **保存为模板承接**：用户主动保存当前内容为模板时，已识别变量和默认值一起被保存。
8. **降级呈现**：当分析结果不足以生成可靠变量时，仍展示完整生成提示，并以轻量说明告知用户可手动编辑或保存模板。

**明确不做**：

- 不自动把每次分析结果保存到模板库。
- 不提供多套候选变量方案让用户选择。
- 不做批量生成、批量变量组合或多组变量对比。
- 不新增模板分享、模板市场或公共模板库。
- 不新增复杂变量类型、条件变量或变量校验规则。
- 不改变参考图上传、图片分析和生成图片的主流程。
- 不重做工作台整体布局和生成结果弹窗。

## 2. 用户旅程和用户故事

### 2.1 核心用户旅程

```text
主旅程：分析图片后快速换变量再生成

1. 用户进入工作台并上传一张参考图。
2. 产品展示分析中状态，左侧保留参考图上下文，右侧编辑区保持稳定。
3. 图片分析完成后，左侧展示风格拆解，右侧自动进入带变量的模板编辑视角。
4. 用户在右侧看到变量列表：
   - 主体内容：默认值为参考图中的主体
   - 场景环境：默认值为参考图中的场景
   - 视觉风格：默认值为参考图的风格描述
   - 光线色彩：默认值为参考图的光线或色彩描述
   - 其他明确要素：如材质、构图、情绪等
5. 用户不修改任何变量时，完整生成提示已经可用，可以直接点击生成。
6. 用户若想换内容，只修改对应变量，例如把主体内容从“玻璃香水瓶”改为“陶瓷咖啡杯”。
7. 完整生成提示同步反映变量变化，用户确认后点击生成。
8. 生成结果通过对话框展示；关闭后用户回到原变量编辑状态，继续调整或保存为模板。

异常旅程：分析结果只支持部分变量

1. 图片分析完成，但只有主体和场景足够明确。
2. 右侧只展示可信变量，不强行补出风格或材质变量。
3. 用户仍可直接生成，也可进入完整提示补充细节。

异常旅程：无法识别稳定变量

1. 图片分析完成，但结果不足以拆出可靠变量。
2. 右侧展示完整生成提示，不显示空变量表单。
3. 产品说明本次未识别到稳定可替换项，用户仍可编辑文本、生成图片或手动保存模板。

异常旅程：用户切换参考图重新分析

1. 用户更换参考图并重新分析。
2. 新分析完成后，变量默认值以新参考图为准。
3. 旧参考图的变量值不会混入新分析结果。
```

### 2.2 用户故事

**核心用户故事**

| # | 用户故事 |
|---|----------|
| US-01 | 作为创作者，我希望图片分析完成后自动看到可替换变量，以便我不需要手动从整段提示词里找可改内容 |
| US-02 | 作为创作者，我希望变量默认值来自参考图内容，以便我能理解每个变量代表什么，并能不修改就直接生成 |
| US-03 | 作为创作者，我希望能快速修改主体、场景或风格变量，以便基于同一分析结果生成新的画面 |
| US-04 | 作为创作者，我希望完整生成提示会随变量变化同步更新，以便我确认最终会拿什么内容去生成 |
| US-05 | 作为创作者，我希望分析后生成的变量模板可以继续保存，以便把一次好的反向分析沉淀成可复用模板 |

**延伸用户故事**

| # | 用户故事 |
|---|----------|
| US-06 | 作为偏高级的创作者，我希望能切换到完整文本直接编辑，以便微调不适合用变量表达的细节 |
| US-07 | 作为遇到不清晰参考图的用户，我希望产品不要硬凑变量，以便我不会被错误默认值误导 |
| US-08 | 作为连续创作的用户，我希望更换参考图后变量自动更新为新图内容，以便不会误用上一张图的信息 |

|------|----------|-----------|

### 3.3 业务规则

1. **自动变量化规则**：只有图片分析成功并产出可编辑内容后，才自动生成变量模板；分析中、分析失败或没有可编辑内容时不生成变量。
2. **默认值规则**：变量默认值必须来自参考图分析出的具体内容；不得用空值或泛化占位作为首态默认值。
3. **核心变量规则**：参考图信息足够明确时，变量应优先覆盖主体内容、场景环境、视觉风格、光线色彩；其他变量只在内容明确且对再创作有帮助时出现。
4. **克制变量规则**：同一含义只保留一个变量；不把整段描述拆成过多碎片，避免用户面对难以理解的变量列表。
5. **可直接生成规则**：分析完成后的首态必须是一条完整可用的生成提示；用户不填写、不确认变量也能点击生成。
6. **变量同步规则**：用户修改变量值后，完整生成提示应同步反映变化；用于生成的内容以用户当前看到的结果为准。
7. **文本编辑规则**：用户切换到完整文本并手动编辑后，文本编辑结果可直接用于生成；产品不得在无提示的情况下用变量结果覆盖用户手动编辑内容。
8. **保存承接规则**：用户主动保存为模板时，当前变量含义、当前值和完整模板内容一起保存，便于下次继续填值。
9. **重新分析规则**：更换参考图或重新分析成功后，变量默认值应以最新参考图为准；旧图变量不得自动带入新图结果。
10. **降级规则**：当变量识别不足或不可靠时，产品应展示完整生成提示并说明原因，不展示空变量表单，也不阻断生成。
11. **视觉一致规则**：自动变量化能力应放在现有右侧编辑区内，不新增独立页面，不改变工作台左右区主结构。

## 4. 验收标准

- AC-01：分析完成后自动出现变量模板
  前置：用户上传参考图并等待图片分析成功。
  动作：用户查看右侧编辑区。
  结果：右侧默认展示带变量的模板编辑视角；在参考图信息足够明确时，能看到主体内容、场景环境、视觉风格、光线色彩等变量项。

- AC-02：变量默认值来自参考图内容
  前置：分析结果中包含明确的主体、场景、风格或光线信息。
  动作：用户查看变量列表。
  结果：每个变量都有已填好的默认值，默认值表达的是参考图中的实际内容，而不是空白或泛化占位。

- AC-03：默认值可直接生成
  前置：图片分析成功，右侧已展示自动变量模板。
  动作：用户不修改任何变量，直接点击生成图片。
  结果：生成入口可用；用于生成的完整提示包含所有默认值，不出现未填变量或空值。

- AC-04：修改变量会同步生成提示
  前置：右侧展示自动变量模板。
  动作：用户修改一个变量值，例如主体内容或场景环境。
  结果：完整生成提示同步反映该变量的新值；用户点击生成时使用更新后的内容。

- AC-05：完整文本编辑不丢失控制权
  前置：右侧已有变量和完整生成提示。
  动作：用户切换到完整文本并手动修改提示内容。
  结果：用户修改后的文本可以直接用于生成；产品不会在无提示的情况下用变量默认值覆盖用户的手动文本。

- AC-06：保存模板承接变量与默认值
  前置：右侧已有自动识别变量，用户可能已修改部分变量值。
  动作：用户点击保存为模板并完成保存。
  结果：保存后的模板包含当前变量项和当前默认值；下次使用该模板时能看到这些变量和默认值。

- AC-07：变量不足时可降级使用
  前置：图片分析成功，但不足以识别稳定变量。
  动作：用户查看右侧编辑区。
  结果：产品展示完整生成提示和轻量说明，不展示空变量列表；用户仍可编辑、保存或生成。

- AC-08：重新分析不会沿用旧变量
  前置：用户已完成一次分析并看到变量默认值。
  动作：用户更换参考图并等待新分析成功。
  结果：右侧变量和默认值基于新参考图重新生成；上一张参考图的变量值不会自动混入新结果。
