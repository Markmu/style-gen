# T06: 首页（前端）

## 任务概要

- **目标**: 实现首页，包含产品价值展示和参考图上传入口，上传后跳转工作区
- **依赖**: T01（项目脚手架已就绪）
- **所属模块**: 首页（ui）
- **前置条件**: Next.js 项目可运行，Tailwind CSS 已配置
- **不在范围**: 工作区页面、示例图体验（P1）、SEO 优化细节

## 实现规格

### 1. 页面结构

首页采用单页滚动布局，从上到下：

1. **Hero 区**：产品名称 + 一句话价值描述 + 上传入口
2. **工作流程展示区**：3 步流程（上传参考图 → AI 提取风格配方 → 一键生成同风格新图）
3. **上传入口**（底部重复）

### 2. Hero 区（hero.tsx）

- 标题突出"参考图风格再创作"核心概念
- 副标题说明"上传参考图，AI 提取视觉配方，一键生成同风格新图"
- 视觉上突出，使用大字体和品牌色

### 3. 上传入口（upload-entry.tsx）

- 支持点击选择文件和拖拽上传
- 文件类型限制：image/jpeg, image/png, image/webp
- 文件大小限制：<= 10MB
- 选择文件后不在首页上传，而是携带文件信息跳转到工作区页面
- 跳转方式：使用 `next/navigation` 的 `useRouter`，将文件暂存在内存中传递（可通过 URL 参数或全局状态）

文件传递方案：
- 简单方案：使用 React Context 或全局 store 暂存 File 对象
- 首页选择文件 → 将 File 存入全局状态 → router.push('/workspace') → 工作区从全局状态读取并开始上传

### 4. 价值说明区（value-section.tsx）

- 3 个步骤卡片，每步配图标和简短说明
- Step 1: 上传参考图
- Step 2: AI 提取结构化视觉配方
- Step 3: 一键生成同风格新图
- 简洁直观，Tailwind 实现

### 5. 响应式设计

- 移动端：单列布局，上传区全宽
- 桌面端：Hero 区居中，步骤卡片横排
