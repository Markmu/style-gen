# 04-0 需求设计：Workspace 页面重构

## 0. 文档说明

**产品核心目标**：将 Workspace 页面从"功能模块并列摆放"升级为"围绕创作任务组织的专业工作台"，让用户以最低认知成本完成首轮生成，并为二次迭代提供顺滑入口。

**本需求定位**：03 期完成了品牌视觉体系建立（Luminescent Darkroom + 技术标签）。本期（04）聚焦 Workspace 页面的信息架构重构——重新定义布局结构、任务流组织和状态表达。纯前端重构，不涉及后端 API 或数据模型变更。

## 1. 需求分析与确认

### 1.1 项目背景

**产品当前状态**

Workspace 页面已具备完整功能闭环：上传参考图 → Gemini 视觉分析 → Visual Recipe → 编辑 Prompt → fal.ai/FLUX 生成结果图。全链路可跑通，降级策略（L1-L4）已覆盖。

**存在的具体问题**

1. **任务流不够清晰**：三栏布局缺少步骤递进关系，上传、分析、生成同时出现但优先级不明确，用户无法判断"我现在该关注哪里"
2. **图片主角感不足**：参考图和结果图与控制面板平级排列，没有形成"内容是主角，工具退后"的专业工作台体验
3. **分析结果缺乏创作引导**：Recipe Card 更像技术数据展示，用户跳过编辑直接生成，不理解"理解风格 → 调整意图 → 输出结果"的连贯创作路径
4. **生成完成后重心未切换**：结果图被挤到右栏底部，页面仍保留较强的"分析阶段"结构，缺少以结果为中心的迭代操作区
5. **状态感知薄弱**：没有全局状态指示器，用户需扫描各模块推断当前进度

**本期目标**

将 Workspace 从"三栏功能并列"重构为"两段式工作台"（内容画布 + 决策面板），让用户在任何状态下都能回答：当前处于哪一步、AI 已经产出了什么、下一步最合理的操作是什么、结果如何继续迭代。

### 1.2 核心问题定义

| 问题 | 用户损失 |
|------|---------|
| 三栏并列无步骤感 | 首次使用认知负荷高，用户在上传后不知该看哪里 |
| 图片不是视觉焦点 | 无法充分评估参考图和生成结果质量，影响创作决策 |
| 分析结果缺乏创作引导 | 用户不理解 recipe 与 prompt 的关系，跳过编辑直接生成 |
| 生成后页面重心不切换 | 用户倾向于重新开始而非迭代优化，二次生成率低 |
| 无全局状态感知 | 等待期间焦虑感强，不确定系统是否正常工作 |

### 1.3 关键设计决策

| 决策维度 | 最终选择 | 核心理由 | 否决方案 |
|---------|---------|---------|---------|
| 页面布局 | 两段式：内容画布（60-65%）+ 决策面板（35-40%） | 图片主角感 + 步骤清晰；与 Figma/PS 等专业工具心智模型一致 | 三栏增强（补丁不治本）、单栏流式（桌面端浪费空间） |
| Recipe 披露方式 | 渐进披露：5 字段核心摘要 → 展开完整配方 | 降低首屏认知负荷，按需深入 | 完整展示（首屏信息过载） |
| 结果展示策略 | 生成后画布自动切换为结果图主视图 + 对比切换模式 | 结果导向的重心切换 | 参考图与结果图并排（注意力分散） |
| 右侧面板组织 | 分 3 步：风格拆解 / 生成指令 / 输出设置 | 每步承载一种决策，避免多个同级面板竞争注意力 | — |
| 全局状态感知 | 顶部增加轻量状态栏 | 一眼识别当前阶段，减少认知扫描成本 | — |
| 移动端 | 本轮不纳入 | 聚焦桌面端体验，移动端另行规划 | — |

### 1.4 产品范围

#### P0 — 本期必须交付

1. **两段式布局重构**：左侧内容画布 + 右侧决策面板，替代现有三栏布局
2. **顶部状态栏**：页面标题 + 说明文案（随状态变化）+ 状态标签（未开始/分析中/可生成/生成中/已完成）+ 更换参考图入口
3. **内容画布状态流转**：空态上传区 → 参考图主视图（含风格摘要 Tag）→ 结果图主视图 → 对比查看模式
4. **右侧三步决策面板**：
   - Step 1 风格拆解：核心摘要（主体/场景/光线/色彩/情绪）+ 展开完整配方
   - Step 2 生成指令：Prompt 编辑器 + Negative Prompt 编辑器
   - Step 3 输出设置：宽高比选择 + 画质选择 + 主按钮
5. **按钮文案与面板标题随阶段变化**：生成首版 → 正在生成 → 重新生成；生成指令 → 继续调整指令；输出设置 → 再次生成
6. **所有现有降级策略在新布局中正确呈现**（排队提示、生成不可用、结构化失败、分析不可用）
7. **错误态在新布局中完整处理**（含错误提示卡片、重试按钮）
8. **全局导航栏保留**：根布局的全局导航栏不做任何修改或移除

#### P1 — 建议尽快补充

1. 画布内图片放大查看（Lightbox / 全屏预览）
2. 结果图一键下载（集成到画布工具栏）
3. 风格摘要 Tag 交互优化（点击 Tag 高亮对应 recipe 内容）
4. 画布区域拖拽调整宽度（用户自定义画布/面板比例）

#### P2 — 后续扩展

1. 移动端响应式布局方案
2. 多结果版本管理（历史生成记录、版本对比）
3. 批量生成（多宽高比/多画质同时提交）

#### 明确不做

- 移动端布局
- 后端 API 或数据模型变更
- 新功能范围扩展
- 新依赖引入或大规模组件体系重构
- 全局导航栏的修改或移除

## 2. 用户旅程和用户故事

### 2.1 核心用户旅程

#### 主旅程：首次完整创作流程

```
用户进入 Workspace 页面
  → 看到左侧大尺寸上传区 + 右侧三步预览面板（只读）
  → 顶部状态栏显示"未开始"
  → 上传区引导文案："点击上传 或 拖拽到此"
  → 底部流程说明："① 上传参考图 → ② AI 分析风格 → ③ 生成"
  → 用户点击上传 / 拖拽图片
  → 上传完成后：
      - 左侧画布展示参考图预览
      - 自动触发分析
      - 状态栏切换为"分析中"
      - 右侧 Step 1 展示分析进度
  → 分析完成后：
      - 左侧画布展示参考图主视图 + 底部风格摘要 Tag
      - 右侧 Step 1 展示核心摘要（主体/场景/光线/色彩/情绪），可展开完整配方
      - 右侧 Step 2 展示可编辑的 Prompt + Negative Prompt
      - 右侧 Step 3 展示输出设置 + "生成首版"按钮 enabled
      - 状态栏切换为"可生成"
  → 用户浏览风格摘要，确认 AI 理解正确
  → （可选）展开查看完整配方 / 微调 Prompt
  → 选择宽高比和画质 → 点击"生成首版"
  → 状态栏切换为"生成中"
  → 画布保持参考图可见，Step 3 按钮变为"正在生成" loading 态
  → 生成完成后：
      - 左侧画布自动切换为结果图主视图
      - 画布顶部出现切换栏：[结果图] [对比查看]，右侧 [下载]
      - 右侧面板切换为迭代模式：
        · 顶部展示本次生成参数摘要
        · Step 2 标题变为"继续调整指令"，保留上次 Prompt
        · Step 3 标题变为"再次生成"，按钮变为"重新生成"
      - 状态栏切换为"已完成"
  → 用户可继续：对比查看 / 调整 Prompt 重新生成 / 更换参考图重新开始
```

#### 异常旅程

- **分析失败**：Step 1 展示错误信息 + 重试按钮；参考图保留在画布中；用户可重试或更换参考图
- **生成失败**：Step 3 展示错误信息 + 重试按钮；Prompt 和参数保留，用户可直接重试
- **生成服务降级**：Step 3 顶部展示降级提示，生成按钮 disabled；分析和编辑功能仍可用
- **风格结构化失败**：Step 1 展示降级提示；Step 2 预填原始分析文本，用户可手动编辑后继续生成
- **分析服务不可用**：Step 1 展示降级提示，风格配方区域置灰

### 2.2 用户故事

#### P0 用户故事（覆盖核心链路）

| ID | 用户故事 | 验收要点 |
|----|---------|---------|
| US-01 | 作为首次使用 Workspace 的用户，我希望一进页面就知道该做什么、整个流程有几步，以便我能自信地开始 | 空状态下右侧面板展示 3 步预览（只读）；顶部状态栏显示"未开始"；上传区占据画布主要空间并有引导文案和流程说明 |
| US-02 | 作为上传了参考图的用户，我希望参考图以大尺寸展示在页面最显眼的位置，以便我能确认上传质量 | 上传完成后参考图填充左侧画布（60%+ 宽度）；画布底部展示风格摘要 Tag |
| US-03 | 作为等待分析结果的用户，我希望知道系统正在做什么 | 状态栏显示"分析中"；Step 1 展示分析进度提示 |
| US-04 | 作为拿到分析结果的用户，我希望先看到风格的核心摘要而不是一堆专业字段 | Step 1 默认展示 5 字段核心摘要；下方有"展开完整配方"入口 |
| US-05 | 作为准备生成的用户，我希望顺着"看懂风格 → 调整描述 → 选参数 → 点生成"的路径自然完成操作 | 右侧面板 Step 1→2→3 垂直排列；当前可操作步骤视觉突出 |
| US-06 | 作为生成完成的用户，我希望结果图自动成为页面的视觉中心 | 生成完成后画布切换为结果图；顶部出现切换栏和工具按钮；右侧切换为迭代模式 |
| US-07 | 作为想对比参考图和结果图的用户，我希望在同一视图中快速切换 | 画布切换栏提供"对比查看"；切换后画布内左右分栏等宽展示 |
| US-08 | 作为对结果不满意想重新生成的用户，我希望在保留上次 Prompt 的基础上微调后重新生成 | 迭代模式下 Prompt 保留上次文本；按钮变为"重新生成" |
| US-09 | 作为遇到错误的用户，我希望知道出了什么问题、能不能重试、下一步可以做什么 | 错误态提供重试和更换参考图两个出口；已有内容不被清除 |

#### P1 用户故事

| ID | 用户故事 | 验收要点 |
|----|---------|---------|
| US-10 | 作为查看结果图的用户，我希望一键下载高清原图到本地 | 画布工具栏提供下载按钮，点击触发浏览器下载 |
| US-11 | 作为想细看图片的用户，我希望放大查看参考图或结果图的细节 | 画布提供放大按钮，点击后全屏预览 |

|------|---------|-----------|
| **未开始** | 左侧：大尺寸空态上传区（含引导文案和流程说明）；右侧：三步预览（只读，按钮 disabled）；状态栏："未开始" | 上传参考图 |
| **上传中** | 左侧：上传区显示上传进度；右侧不变；状态栏保持"未开始" | 等待上传完成 |
| **分析中** | 左侧：参考图预览；右侧 Step 1 展示分析进度；状态栏："分析中" | 等待分析完成 |
| **可生成** | 左侧：参考图填充画布 + 底部风格 Tag；右侧 Step 1 摘要 + Step 2 编辑器 + Step 3 参数和"生成首版"按钮；状态栏："可生成" | 浏览摘要 → 编辑 Prompt → 选参数 → 点生成 |
| **生成中** | 左侧：保持参考图可见；右侧 Step 3 按钮"正在生成" loading + disabled；状态栏："生成中" | 等待生成完成 |
| **已完成** | 左侧：结果图主视图 + 切换栏（结果图/对比查看/下载）；右侧：生成参数摘要 + 迭代编辑器 + "重新生成"按钮；状态栏："已完成" | 评估结果 → 对比 / 下载 / 迭代 / 更换参考图 |
| **错误态** | 对应步骤区域展示错误提示卡片 + 重试按钮；其他区域和已有内容保持可用 | 重试 / 更换参考图 / 继续编辑 |

### 3.3 业务规则

#### 上传规则

- 支持格式：JPG、PNG、WebP，最大 10MB
- 上传方式：点击选择文件 + 拖拽上传
- 上传后自动触发分析，无需额外确认
- 新上传替换旧图片并重置所有后续状态

#### 步骤解锁规则

| 条件 | Step 1（风格拆解） | Step 2（生成指令） | Step 3（输出设置） |
|------|-------------------|-------------------|-------------------|
| 未开始 | 只读预览 | 只读预览 | 只读预览（按钮 disabled） |
| 分析中 | 进度展示 | 只读预览 | 只读预览（按钮 disabled） |
| 可生成 | 摘要展示（可展开完整配方） | 可编辑 | 可操作（按钮 enabled） |
| 生成中 | 摘要展示 | 可编辑但提示"生成中" | 按钮"正在生成" loading + disabled |
| 已完成 | 折叠为参数摘要 | 可编辑（保留上次内容） | 可操作（按钮文案"重新生成"） |

#### 画布视图规则

- 默认视图跟随状态：无参考图 → 上传区，有参考图未生成 → 参考图，已生成 → 结果图
- 对比查看仅在"已完成"状态可用，左右分栏等宽展示参考图与结果图
- 切换对比视图不改变右侧面板状态

#### 风格摘要规则

- 核心摘要字段固定 5 个：主体、场景、光线、色彩、情绪
- Tag 展示：画布底部 pill/tag 形式，3-5 个关键词
- "展开完整配方"后展示全部风格配方字段（构图、镜头语言、质感、关键词、保留项、可替换项）

#### 按钮文案规则

| 阶段 | 主按钮文案 | 按钮状态 |
|------|----------|---------|
| 未开始 / 分析中 | 生成首版 | disabled |
| 可生成 | 生成首版 | enabled |
| 生成中 | 正在生成 | loading + disabled |
| 已完成 | 重新生成 | enabled |

#### 状态栏规则

- 始终可见于页面顶部（全局导航栏下方）
- 包含：页面标题、说明文案（随状态变化）、状态标签、"更换参考图"按钮（非"未开始"时显示）
- 说明文案随状态变化：
  - 未开始："上传参考图，提炼风格特征，再生成可继续迭代的新图"
  - 可生成："AI 已提炼出参考图的风格特征，你可以继续调整生成意图"
  - 已完成："已生成首版结果，可继续对比、下载或迭代"

#### 降级态呈现规则

- **排队提示**（>60s）：对应步骤区域内展示排队提示卡片
- **生成不可用**：Step 3 顶部展示降级提示，生成按钮 disabled
- **风格结构化失败**：Step 1 顶部展示降级提示，Step 2 预填原始分析文本
- **分析不可用**：Step 1 顶部展示降级提示，风格配方区域置灰
- 统一视觉样式：amber 色系警告卡
